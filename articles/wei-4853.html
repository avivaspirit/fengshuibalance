💡 สรุปใจความสำคัญ: 5 เมษายน - 6 พฤษภาคม 2558 เป็นเดือนมะโรง เดือนนี้ มีฤกษ์เปิดทรัพย์ 4 ทิศ ทั้งหมด 3 วัน ( รวมวันที่ 1 พค. ด้วย // ฉบับที่ลอกเลียนไป จะแจ้งว่า มี 2 วัน ) .... เดือนนี้ ดาว 5...

5 เมษายน - 6 พฤษภาคม 2558 เป็นเดือนมะโรง เดือนนี้ มีฤกษ์เปิดทรัพย์ 4 ทิศ ทั้งหมด 3 วัน ( รวมวันที่ 1 พค. ด้วย // ฉบับที่ลอกเลียนไป จะแจ้งว่า มี 2 วัน )

เดือนนี้ ดาว 5 เบญจภูติ ( ศัพท์บัญญัติของชมรมฯ ) ทั้งดาวประจำปี และประจำเดือน โคจรมาลงตำแหน่งเดียวกัน คือ ทิศตะวันตก + ทิศนี้ เป็นอสูรประจำปี ( ห้ามกระทบ ) เรียกทิศมหาวิบัติ

  • ห้ามทุบเคาะเจาะตอก ในทิศนี้เด็ดขาด

... จะเกิดเหตุรวดเร็ว รุนแรง

  • หากหน้าบ้านเป็นทิศนี้ และการค้าฝืดเคือง

... การงาน การเรียน สะดุด ติดขัด ... ให้แก้ไขด้วย เครื่องหมาย "กั้ว เลข 1" ... หาได้จากหนังสือ ปฎิทินฤกษ์มงคล 2558 ปีแพะ ... ขั้นตอน วิธีการ ตามหน้า 89 ครับ
