【 Quiz 】 ไปจัด #ฮวงจุ้ย บ้านเดี่ยวให้ FanPage The Village Cottage บางกรวย-ไทรน้อย บ้านราคาประมาณ 5 ล้านกว่าขึ้นไป

หลังจากเปิดประตูบ้านเข้าไป พบว่า ฝั่งตรงข้ามประตูบ้าน เป็นกำแพงทึบ ( สมัยนิยม มักเป็นหน้าต่างขนาดใหญ่ ) สันนิษฐานได้ว่า มีการปรึกษาซินแสในการออกแบบ เพราะฝั่งตรงข้ามประตูเป็นประธาน ประธานต้องนิ่ง มั่นคง กำแพงทึบจึงดี หน้าต่างหลบไปอยู่ด้านข้างซ้ายขวาแทน .. วัดองศาหลังบ้าน ด้วยเครื่องมือเฉพาะได้ 316 NW เป็นองศารุ่งเรืองในยุค 8 ( ลองวัดด้วยมือถือ องศาที่ได้ผิดความจริงไปมาก ) ดังนั้น จึงไม่สามารถเอาองศามือถือมาจัดฮวงจุ้ยได้ ใช้มาดูฤกษ์พอได้ครับ

*** กรุณาฝึกสังเกตุ วิเคราะห์ ***

หากเราดูจากแบบ Plan ชั้น 1 เฉพาะแง่ชัยภูมิ มีจุดที่ควรปรับแบบ 3 จุด

ในด้านการวิเคราะห์บทบาท #ดาว9ยุค ด้านหลังเป็นบารมี ( กำแพงหลังทึบ ) ด้านหน้าเป็นโชคลาภประจำยุค ด้านหน้าซ้ายมือ ( เมื่อยืนในบ้าน หันไปหน้าบ้าน ) เป็นดาวโชคลาภหนุน ดาว 9 จึงแนะให้จัดทำ บ่อปลา หรือน้ำพุ 9 หัว ซึ่งตรงกับที่สถาปนิกนำเสนอไว้พอดี ( เป็นส่วนเสริม ทำแล้วได้ลาภ )

การตกแต่งภายในยิ่งสำคัญ ต้องสอดคล้องกัน เพราะหากจัดวางผิด กลับจะเสียหาย

ทางเจ้าบ้านได้ให้สถาปนิกออกแบบใหม่ เพิ่มส่วนต่อเติม ย้ายครัวไปด้านหลัง หลังจาก วิเคราะห์ตำแหน่งทิศทางลมแล้ว จึงได้ขอให้สถาปนิกเว้ากำแพงด้านข้างของส่วนต่อเติม เข้ามา 1 เมตร เพื่อดักลมให้เข้าห้องครัว ให้อากาศได้ถ่ายเท ไหลเวียน ไม่เหม็นอับ ( ทางสถาปนิกทั้ง 2 ท่านเห็นดีด้วย ) ระหว่างห้องครัวที่ต่อใหม่ มีประตูเปิดปิด กรณีทำอาหาร กลิ่นจะได้ไม่มารบกวน

ชั้นล่างออกแบบใหม่ ซึ่งเหมาะสมและดีกว่าแบบปัจจุบัน ทางเราได้ปรับรายละเอียดในบางจุด เพื่อเสริมตำแหน่งบารมีให้เด่นชัดขึ้น และรับกระแสโชคลาภได้ดีขึ้น ( ตรงนี้ ขอเป็นรายละเอียดส่วนตัวของเจ้าบ้าน )

หลังจากนั้น จะเป็นการวิเคราะห์ดวง ทำนายอดีตให้ถูกต้อง ( และวางแผนสำหรับอนาคต ) เพื่อหาราศีปรับดวงให้ดีขึ้น โดยใช้ทิศหัวเตียง ถ้าสุขภาพอ่อนแอ ต้องเน้นปรับให้แข็งแรงก่อน แต่ดวงที่ปกติดีอยู่แล้ว หากเป็นนักเรียน นักศึกษา จะเน้นปัญญา ผู้ใหญ่วัยทำงาน จะเน้นโชคลาภ ห้องสามีภรรยา จะซับซ้อนสุด เพราะต้องหาราศีทิศที่เหมาะกับดวงทั้ง 2 คน

ชั้นบน มีการปรับทิศหัวเตียงตามดวงชะตาของผู้นอน และสลับห้องกันเล็กน้อย เพื่อให้ดีที่สุดสำหรับทุกคน จากนั้น กำหนดตำแหน่งสำคัญอื่น ๆ รวมถึง โต๊ะทำงาน Air ( บางหลังเพิ่ม ตู้ Safe )

การปรับแก้แบบ มีรายละเอียดพอสมควร แต่ก็มีเหตุผลทางปฏิบัติรองรับเกือบทุกประเด็น เช่น จำนวนประตูเข้าบ้านจาก 3 เหลือ 2 ( ประตูหน้า 1 +หลัง 1 ตัดประตูข้างที่ใช้น้อยออก ) ป้องกันการหลงลืม เพิ่มความปลอดภัย บางประเด็น อาจเป็นเหคุผลทางด้านฮวงจุ้ย

เมื่อสอบถามทางสถาปนิกแล้ว เรื่องความยุ่งยากในการปรับแก้ไข ทั้ง 2 ท่านบอก ไม่ยุ่งยากอะไร เพราะไม่ได้ทุบแก้โครงสร้างหลักเลย แค่ปรับรายละเอียดในการออกแบบเท่านั้น

ขั้นตอนต่อไป ให้ทางสถาปนิกปรับแก้แบบ ตรวจกับเจ้าบ้าน แล้วส่งมาให้ตรวจซ้ำอีกรอบก่อนลงมือทำจริง และจะได้หาฤกษ์มงคลกระทบต่อเติม เมื่อต่อเติมเสร็จ จึงหาฤกษ์เข้าอยู่อาศัย ชี้แนะพิธีเข้าอยู่ให้ถูกต้อง

NOTE 1 บ้านฝั่งตรงข้าม เป็นทิศทางรุ่งเรืองเช่นกัน แต่ดีไม่เท่ากัน อย่างไรก็ตาม อาจเหมาะกับดวงเรามากกว่า ก็เป็นได้ !!

NOTE 2 บ้านหลังที่ดีที่สุด เมื่อมองจากภายนอก คือ บ้านตัวอย่าง ( สำหรับที่นี่เท่านั้น )

NOTE 3 สถาปนิกขอนามบัตร เผื่อแนะนำลูกค้าให้ เพราะทำงานร่วมกันได้ดี มีหลักการ และเหตุผล
