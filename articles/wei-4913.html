ดวงจีน (Destiny)

แพทย์แผนจีน จะดูสมดุลของธาตุ

📅 วันที่: 2016-06-22 📂 หมวดหมู่: ดวงจีน (Destiny) 📈 ความนิยม: 0

💡 สรุปใจความสำคัญ: แพทย์แผนจีน จะดูสมดุลของธาตุ ดวงจีน ใช้ 5 ธาตุวิเคราะห์ปรับสมดุลเช่นเดียวกัน ธาตุน้ำอ่อนแอ ความเสี่ยงโรค ... ไต - กระเพาะปัสสาวะอักเสบ - มดลูก - หู - กระดูก...

แพทย์แผนจีน จะดูสมดุลของธาตุ ดวงจีน ใช้ 5 ธาตุวิเคราะห์ปรับสมดุลเช่นเดียวกัน ธาตุน้ำอ่อนแอ ความเสี่ยงโรค ... ไต - กระเพาะปัสสาวะอักเสบ - มดลูก - หู - กระดูก

หลักการเบื้องต้น

  • หากธาตุน้ำอ่อนแอ ต้องเสริมน้ำ

... ด้วยธาตุทอง ( นอนหรือ นั่งพิงทิศตะวันตก ) ... หรือธาตุน้ำ ( พิงทิศเหนือ )

  • ธาตุน้ำปกติ แต่เย็นจัด ก็ป่วย

... ปรับแก้ด้วย ธาตุไม้ ( พิงทิศตะวันออก ) ... หรือธาตุไฟ ( พิงทิศใต้ )

  • ธาตุน้ำแข็งแรงเกิน ก็ป่วย ต้องสมดุล

เป็นพื้นฐาน พอให้เห็นภาพกว้าง ๆ ยังมีรายละเอียดลึก ๆ มากกว่านี้อีกมาก รวมถึงบางอาการ บางลักษณะ มีกลับไปกลับมา ไม่แน่นอน ยากต่อการวินิจฉัย

จึงต้องอ่านดวงแม่นยำ วิเคราะห์อาการโรคได้ แล้วเลือกทิศ ราศี และองศามาปรับแก้ ฯลฯ

ดวงป่วย ต้องแก้อาการป่วยก่อน ซินแสบางคนเน้นเรื่องเงินทอง เน้นบารมี หาเงินได้มากมาย จ่ายค่ายาหมด มีประโยชน์อะไร !

นักเที่ยวกลางคืนทั้งหลาย ดื่มเหล้า Alcohol นอนดึก เป็นภาระหนักแก่ไต อายุมากแล้ว ต้องมานั่งฟอกเลือด รอรับบริจาคไต ( ซึ่งโอกาสได้น้อยมาก ) อย่าทำลายชีวิตตนเอง เป็นภาระให้ลูกหลาน

Share ให้แก่ นักเที่ยวกลางคืน คนดื่มเหล้า คนไม่ดูแลสุขภาพ ... ทาน Junk Food อาหารรสจัด ( โดยเฉพาะรสเค็ม ) ตาสว่างเสียทีเถิด

จัดปรับพื้นที่และสถาปัตยกรรมตามหลักฮวงจุ้ย

ให้คำปรึกษาและวิเคราะห์พื้นที่จริงสำหรับบ้าน คฤหาสน์ ออฟฟิศ และวางตำแหน่งศาลเจ้าที่/ตี่จู้ โดยอาจารย์สุภชัย วิวัฒนะประเสริฐ
