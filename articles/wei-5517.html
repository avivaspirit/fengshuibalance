ท่อปล่อยความร้อน ผลกระทบเหมือนเมรุ

ในแง่ความเป็นจริง ... กลิ่น ควัน ขี้เถ้า เป็นอันตรายต่อสุขภาพ . การแก้ไข ... ให้ท่อสูงกว่านี้ ... แต่หากอาคารเราสูงก็ยังคงเจอปัญหา ... ใช้งานให้น้อย ทั้งความถี่ และปริมาณ ... หาต้นไม้มาบัง ... กรณีอยู่ใกล้ อาจต้องทำกำแพงทึบ .

ในแง่ฮวงจุ้ย ... เผาไหม้ คือ ทำลาย ... หากเป็นดาวที่ดี ยิ่งเสียหาย ... ดาวลาภที่ดี จะเสียเงิน ... ดาวบารมี จะป่วยเรื้อรัง ... หน้าที่การงานมีปัญหา ... ซึ่งบางทีเราอาจมาองข้ามไป . การแก้ไข ... ท่อปล่อยความร้อน ( ไฟ ) ... ทำกำแพงปิดที่ตรงท่อ ... ด้านนอกทาสีเหลือง หรือน้ำตาลอ่อน ( ดิน ) ... ไฟ ให้กำเนิด ดิน ... ( เปลี่ยนศัตรูเป็นมิตร ) ... ผลกระทบด้านฮวงจุ้ยลดลง ( ดิน ) . แต่ต้องแก้ ... ผลกระทบตามความเป็นจริงด้วย ( หยาง ) ... ปลูกต้นไม้ ช่องหน้าต่างที่เหลือ .

จัดปรับพื้นที่และสถาปัตยกรรมตามหลักฮวงจุ้ย

ให้คำปรึกษาและวิเคราะห์พื้นที่จริงสำหรับบ้าน คฤหาสน์ ออฟฟิศ และวางตำแหน่งศาลเจ้าที่/ตี่จู้ โดยอาจารย์สุภชัย วิวัฒนะประเสริฐ
