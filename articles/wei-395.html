ได้วิเคราะห์ดวงสาวน้อยปี 1 ... เป็นดวงศิลปิน ช่างคิด ช่างฝัน ... ชอบการประดิษฐ์ สิ่งแปลกใหม่ ... เธอบอกว่า ถูกต้อง 🚩 . แล้วเธอบอกว่า กำลังกลุ้มใจ ... ทางบ้านกำหนดให้เธอ จบแล้ว "รับราชการ" ... ด้วยเหตุผล ทางบ้านเห็นว่า ดี มีความมั่นคง ... แต่ลักษณะงาน ขัดแย้งกับตัวตนเธอสุดกู่ ... เล่าไป ร้องไห้ไป 😭 . ที่เจอบ่อยอีกแบบ คือ ... มันเป็นความฝันของพ่อ ( หรือแม่ ) ... มีอยู่รายหนึ่ง พ่ออยากให้เป็นวิศวะ ... ลูกเรียนจบ ยื่นประกาศนียบัตรให้พ่อ ... แล้วบอกว่า "นี่ครับ วิศวะที่พ่ออยากได้" ... "นับแต่นี้ ผมจะทำตามที่ผมชอบ" ... แล้วเขาหันไปประกอบอาชีพอื่น 🎯 . สรุปแล้วได้อะไรมา ... ได้ความภูมิใจที่เป็น "กระดาษ" ... แต่ลูกต้องระทมทุกข์ 4 ปีกว่า ... ความภาคภูมิใจของคุณ ... มีค่ามากกว่า ความสุขของลูก อย่างงั้นหรือ ‼️ . อย่างหนึ่ง ที่แนะนำได้ ... ลองทำอาหารที่ พ่อหรือแม่ เกลียด ... แล้วบอกว่า "มันดีต่อสุขภาพ" ... ถ้าท่านปฎิเสธด้วยเหตุผลใด ๆ ก็ตาม ... ก็บอกท่านว่า ... อาหารมื้อเดียวท่านยังไม่ชอบ ... แล้ว 4 ปี ( หรือตลอดชีวิต ) ที่เลือกให้ ... เราจะเป็นอย่างไร ? 😢 . บทบาทพ่อแม่ปัจจุบัน ได้เพียงชี้แนะเท่านั้น ... แต่การตัดสินใจสุดท้าย เป็นหน้าที่ของเขา ... แม้ว่าเขาตัดสินใจผิด ... ก็เป็นบทเร็ยนที่เขาต้องยอมรับ ... เพื่อจะเติบโตเป็นผู้ใหญ่แท้จริง 🤩 .
