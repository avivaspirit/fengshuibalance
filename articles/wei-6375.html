ดวงชะตา ปรับแก้ได้ ‼️

องค์รวมของชีวิตคนเรา คือ อิน-หยาง ( หยิน - ออกเสียงผิด ) ดวงชะตากำเนิด คือ อิน ( มืด - ทฤษฎี ) การใช้ชีวิตจริง คือ หยาง ( สว่าง - ปฎิบัติ ) . ตัวอย่าง ดวงชะตาวันเกิดธาตุไฟเปี้ย เกิดในเดือนดินบี่ ฤดูร้อน เจ้าชะตาธาตุไฟสูง มีความเสี่ยงเรื่องอุณหภูมิในร่างสูง ( ความดัน Heat ไขมัน หัวใจ ) นอกจากความร้อนสูง น้ำที่ปรับสมดุล ยังอ่อนแออีก ( ไต กระเพาะปัสสาวะ มดลูก-อัณฑะ ) . จะเห็นว่า พิ้นดวงมีความเสี่ยงหลายโรค ถ้าไม่ปรับแก้ สุขภาพจะมีปัญหาแน่นอน 😅 . การปรับแก้ 🚩

  • ปรึกษาแพทย์
  • นอนหลับพักผ่อนให้เพียงพอ
  • ทานอาหารแนวสุขภาพ ตามเหมาะสม
  • ออกกำลังกาย เหมาะสมกับวัย สุขภาพ

... เช่น สูงอายุ เปลี่ยนจาก วิ่ง เป็น เดินเร็ว

  • ฝึกปฎิบัติสมาธิ / Reiki

. ทั้งหมดนี้ เป็นการแก้ทางปฎิบัติจริง ( หยาง ) . อินแย่ หยางค้ำ ป่วยช้า ป่วยน้อย ฟื้นตัวเร็ว . และบ่อยครั้ง ก็พบว่า สุขภาพดีกว่า พวกดวงดีแต่กำเนิด แต่นอนดู TV ( พวกนี้ อินดี หยางแย่ ) . . ✴️ การปรับเสริม

หยาง

  • อาหารเสริมเล็กน้อย

... อาจจำเป็นสำหรับบางคน ... มากไป เป็นภาระตับตับ ไต .

  • สุขภาพจิต สำคัญมาก

... อยู่ในสังคมดี มีเพื่อน ... ได้แลกเปลี่ยนความรู้ มุมมอง ... ทิศนคติ การใช้ชีวิต ... และอาจได้ Connection เป็นของแถม .

  • ความเครียด Office Syndrome

... สำคัญ ต้องกายภาพบำบัด ... ฝีกสมาธิ / Reiki ช่วยได้มาก . บทความเรื่องความรู้แนวสุขภาพ ดูเพิ่มเติม ได้ที่ Comment . . อิน

  • พื้นดวงชะตาไม่ดี

... สามารถใช้เหรียญปรับแก้ดวงเฉพาะบุคคล ... ( แต่ละคนไม่เหมือนกัน - ยา คนละสูตร ) ... ช่วยผ่อนหนักเป็นเบาได้ ... ได้มาก ได้น้อย ขึ้นอยู่กับรูปดวงชะตา .

  • ฮวงจุ้ยช่วยได้

... เช่น ตัวอย่างดวงนี้ ... หากหัวนอนไปทิศตะวันตก ทอง ส่งเสริม น้ำ ... หรือนอนทิศเหนือ น้ำ ... เพื่อปรับสมดุลดวงชะตา ... ลดความร้อน เพิ่มความเย็น . ... ฮวงจุ้ยทรงพลัง แลกด้วยเงื่อนไขที่มากกว่า ... ไม่ใช่ ทองทุกตัวจะเหมาะกับดวง ... เช่น ทองซิม ( วอก ) จะชงกับวันเสือ ( ในดวง ) . ... นอกจากนี้ ยังต้องมาดูดวงดาวอีก ... ประตูดีหรือไม่ องค์ประกอบภายในห้องเป็นไอย่างไร ... สุดท้ายจะปรับแก้ ต้องดูฤกษ์ .

  • ฤกษ์ยามพิเศษ ช่วยได้

... ฤกษ์ขอพรพิเศษ จัดให้เดือนละหน ... เมื่อสมหวัง ก็มีกำลังใจ .

  • ทำบุญ ช่วยได้

... ลดอัตตา ลดกิเลส ยินดีในการให้ ... ช่วยให้ผู้อื่นมีความสุข เราก็สุขใจ

  • ศาสตร์พลังงาน - สมาธิ / Reiki ช่วยได้

... พื้นฐาน ลดเครียด มีสติ สมาธิ ... ตัดปัญหาที่ไม่จำเป็นออกได้ ปล่อยวาง ... จิตโล่ง หลับสบาย ... เพจจัดนั่งสมาธิเดือนละ 2 หน ... โปรดติตตาม . ... ไม่มีเวลา หรือต้องการให้ได้ผลเร็ว ได้ผลมาก ❤ ... ใช้อุปกรณ์เสริมได้ ( ดูที่ Comment ) . . ขอคำแนะนำ 🚩 ... นอกจากการ Live นำสมาธิแล้ว ... อยากให้จัดกิจกรรมแบบใดอีก ? . นัดพบกินข้าวกลุ่มเล็ก ? จัดงานสัมมนา ( วางแผนอยู่ ) แนะนำได้เลยครับ
