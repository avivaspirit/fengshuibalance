💡 สรุปใจความสำคัญ: การไปกราบไหว้ พระแม่กวนอิม ที่เกาะไหหลำ ... จะต้องเดินผ่าน วงกลมขนาดใหญ๋ ... ซึ่งหากท่านพอรู้ ประวัติศาสตร์จีน ... หากเรายืนกลางลาน แล้วเปล่งเสียง ... กำแพงรอบด้านที่ทำองศาโดยเฉ...

การไปกราบไหว้ พระแม่กวนอิม ที่เกาะไหหลำ ... จะต้องเดินผ่าน วงกลมขนาดใหญ๋ ... ซึ่งหากท่านพอรู้ ประวัติศาสตร์จีน ... หากเรายืนกลางลาน แล้วเปล่งเสียง ... กำแพงรอบด้านที่ทำองศาโดยเฉพาะ ... จะรวมเสียงที่เปล่งออกไป ขึ้นสู่ท้องฟ้า ... กล่าวคือ คำอธิษฐานของท่านส่งขึ้นสวรรค์ ✴️ . หลักการเดียวกับ ลานเทียนฐาน ( ลานขอพรฟ้า ) ... แต่ใช้ประตูสวรรค์ กับชัยภูมิภูเขา ... ( พลังธรรมชาติ ) เป็นการรวมเสียงแทน ... เป็นพลังฟ้าดินบรรจบแท้จริง . นักท่องเที่ยวชาวจีนหลายคนเดินผ่าน ... หลายคนยืนขอพรแบบเงียบ . ข้าพเจ้าได้ให้คณะทัวร์เรา ยืนบนวงกลมสีน้ำตาล ... ห้ามเหยียบตรงกลาง ( เคยอธิบายแล้ว ) ... แล้วสวดมนต์พระแม่กวนอิมพร้อมกัน 😍 ... เสียงก้องดังกังวาลขึ้นสู่เบื้องบน ... แล้วจึงขอพรตามปรารถนา . พระแม่ท่านมี 3 องค์ ⚜ ยืนพิงกัน 3 มุม

  • ปางถือพระสูตร หันหาแผ่นดิน ... ประทานปัญญา
  • ปางถือสายประคำ หันหน้าออกสู่ทะเลจีนใต้ ... เมตตา
  • ปางถือดอกบัว หันหน้าออกสู่ทะเลจีนใต้ ... สันติ

. มีความสูง 108 เมตร ใช้เวลาก่อสร้างประมาณ 6 ปี ฐานด้านใน บรรจุพระแม่ขนาดต่าง ๆ มากมาย . คณะเรานำสร้อยไข่มุกไปถวาย 4 เส้น 😇 ถวายพระแม่ไว้ 3 และนำกลับ 1 ( มิได้เป็นเคล็ดลับประการใด ) . หลังจากถวายท่าน ... แวบเดียว สร้อยก็หายไป ‼️ ... ไปอยู่ในมือคนจีนหมด 555 . หากใครจะไปไหว้ ... ช่วงหน้าร้อน คนน้อย แต่อากาศร้อนมาก 🥵 ... ช่วงอากาศดี คนเยอะมาก . หลังจากกลับมา ... ข้าพเจ้าโชคดีหลายเรื่องติดกัน ... ได้งานฮวงจุ้ย โครงการบ้านจัดสรรขนาดใหญ่ 🚩 ... ผลิตภัณฑ์ Miracles369 ขายดีแบบเหลือเชื่อ 🤩 ... คงต้องหาโอกาสไปไหว้ใหม่อีกแน่นอน ... คงเป็นปีหน้าครับ 🥰
