【 เฉลย 】 ซ้าย คือ กระจกนูน + สิงห์คาบดาบ ควาหมายคือ สะท้อนออก และป้องกัน เป็นสิ่งประดิษฐ์เพิ่มเติมในช่วงหลัง ไม่ใช่หลักการของฮวงจุ้ยดั้งเดิม

ตามระบบของชมรมภูมิโหราศาสตร์ ของท่านอ.เกรียงไกร บุญธกานนท์ ผู้เป็นอาจารย์ข้าพเจ้า ท่านจะเน้นหลักการ "เปลี่ยนศัตรูเป็นมิตร" ปรับสภาพกระแสที่ไม่ดี ให้ส่งเสริมเรา ดีด้วยกันทุกฝ่าย เป็นแนวทางฮวงจุ้ยแท้จริง คือ ปรับสมดุล

หากเราใช้หลักการ "ต่อสู้ศัตรู" ดังภาพ ( เป็นบทบาทของผซินแสฮ่องกง ) หากพลังของบ้านดี ดวงเราดี เราได้เปรียบ แต่หากเราตก ทุกอย่างจะเข้ามาปะทะ เสียเปรียบ เกิดเรื่องราวไม่รู้จบ *** ไม่แนะนำทุกกรณี ***

และกระจก ก่อนจะสะท้อน จะดึงภาพเข้ามาก่อน ดังนั้น ดึงเรื่องไม่ดีเข้ามาตัว ย่อมไม่ถูกต้อง ลองไปสังเกตุ อาคารใน Singapore จะเห็นว่ามีใช้น้อยมาก ถ้ามี สันนิษฐานได้ว่า ซินแสฮ่องกงเป็นคนจัดฮวงจุ้ยให้

ขวา เป็นรูปทรงน้ำเต้า มีหลายความหมาย แต่ภาพรวม คือ ดูด ทั้งพลังที่ดีและไม่ดี *** มาเก็บกัก ขังไว้ ดังนั้น ไม่ว่าจะดีหรือไม่ดี ท่านก็ไม่ได้

น้ำเต้าที่ได้ผล ต้องเป็นน้ำเต้าแท้ ไม่ใส่สิ่งประดิษฐ์ หรือรูปทรงคล้ายคลึง

สุดท้าย ถ้าท่านอยู่ฝั่งตรงข้าม ก็ไม่มีความจำเป็นต้องแก้ไขใด ๆ เพราะ กระจก เขาก็ดูดสิ่งไม่ดีไว้ในตัว น้ำเต้า ก็เช่นเดียวกัน

ไม่แนะนำให้ติดสิ่งเหล่านี้ โดยเฉพาะติดแล้ว ทำให้เพื่อนบ้านไม่พอใจ เคยมีรายการ TV สัมภาษณ์หญิงท่านหนึ่ง ( ใครหาเจอ แนะนำด้วยครับ ) เคยติดกังหัน ยันต์รอบบ้าน จนคนอื่นเขามองว่า แปลกประหลาด และไม่มีอะไรดีขึ้น แต่กลับเสียเงินซื้อติดอันที่พังไป หลังจากเสียเงินหลายรอบ สุดท้ายเอาออกหมด ชีวิตกลับดีขึ้น ( อย่างน้อยเพื่อนบ้านก็เลิกมองด้านลบ )

ทั้งหมดนี้ ไม่ใช่ฮวงจุ้ยตามหลักวิชาดั้งเดิม ระบบฮวงจุ้ยที่แท้ จะเน้นสภาพแวดล้อม ( ชัยภูมิ ) กระแสที่ดี มีพลังโชคลาภ และบารมี ( ทิศทางองศา ) แล้วปรับตัวเราให้สมดุล เข้าหากัน ( ดวงชะตา ) ในช่วงเวลาที่ถูกต้อง เหมาะสม ( ฤกษ์ยาม )
