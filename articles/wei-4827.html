ฮวงจุ้ยไม่ดี ทำให้มีบุตรยาก

ไร้บุตร หมายถึง ไม่มีลูก ไม่มีบุตรหลานสืบสกุล ดังนั้น สำหรับคนจีน การมีแต่ลูกผู้หญิง ก็เรียกไร้บุตรเช่นกัน ( ไม่มีคนสืบทอดสกุล )

การวิเคราะห์ใด ๆ ต้องพิจารณาองค์ประกอบทั้ง อินและหยาง ร่วมกัน

ในสังคมปัจจุบัน ( หยาง ) ภาวะไร้บุตร มีลูกยาก มีลูกน้อย พบได้บ่อยขึ้น เนื่องด้วย

  • สภาพแวดล้อม อากาศเป็นพิษ
  • อาหารเป็นพิษ
  • งานหนัก ไม่มีเวลา หรือเหนื่อยจนไม่มีแรง
  • เครียดจัด
  • ปัญหาสุขภาพ เช่น น้ำหนักมากเกิน ไม่แข็งแรง
  • วิถีการกิน : ทานอาหารไร้ประโยชน์ เสพของมึนเมา

ให้โทษ ( เหล้า บุหรี่ )

  • เวลาไม่ตรงกัน ทำงานเป็นกะ
  • ยังไม่พร้อม รอจนพร้อมก็อายุมาก โอกาสมีก็น้อยลง
  • แต่งงานอายุมากขึ้น
  • ปัญหาค่าครองชีพ บางทีเลี้ยงไหวแค่สองคน มีแต่ลูกผู้หญิง
  • ลักษณะสังคมเมือง ไม่ได้อยู่เป็นครอบครัวใหญ่ ไม่มีแม่บ้าน
  • เลี้ยงดูกันเอง ก็ไม่ต้องการจำนวนบุตรมาก

ไม่มีลูก มีลูกยาก ในแง่วิชาฮวงจุ้ย ( อิน )

  • สุสานบรรพบุรุษ
  • ตั้งผิดทิศ ( ปะทะปีเกิด ขัดแย้งหรือให้โทษกับปีเกิด )
  • ตำแหน่งลูกมีปัญหา
  • องศาไม่ดี
  • ฤกษ์ผิด
  • ป้ายแตกร้าว
  • องค์ประกอบชัยภูมิอื่น ๆ เช่น ไม่มีภูเขาหนุนหลังที่ดี
  • เดิมเคยดี แล้วไม่ดีในช่วงหลัง อาจเกิดจากการเปลี่ยนยุค
  • สภาพชัยภูมิเปลี่ยนไป เช่น ตัดถนน เจาะอุโมงค์
  • บ้านพักอาศัย ( องศา ทิศทาง )
  • เป็นทิศทาง "ล้มเหลว" ลาภอยู่หลังบ้าน บารมีอยู่หน้าบ้าน
  • ตำแหน่งลาภวิบัติ มีบทบาท
  • บารมีประจำยุค เข้าสู่ศูนย์กลาง
  • บารมีประจำยุค เป็นตำแหน่งประตู *
  • ลาภประจำยุค หมดสภาพ *
  • องศาหมดสภาพ
  • ชัยภูมิภายนอก และภายใน
  • เมรุ ขณะเผาไหม้ จะมีสารไดออกซิน

ส่งผลเรื่องความแข็งแรงของเชื้ออสุจิ

  • นอนตรงประตู นอนใต้คาน ...
  • เตาไฟกลางหลังบ้าน ( ประธาน )
  • ห้องส้วมกลางหลังบ้าน *
  • ดวงชะตา
  • หญิงมีบุตรยาก
  • ชายมีบุตรยาก
  • ต่างฝ่ายไม่ได้มีบุตรยาก แต่รวมกันแล้วมีบุตรยาก
  • ตำแหน่งทิศหัวนอน ทำให้ดวงชะตามีบุตรยาก
  • ฤกษ์แต่งงาน
  • บางครั้งก็เป็นตัวแก้ให้มีบุตร

แต่หลายครั้งก็เป็นประเด็นทำให้ไม่มีบุตร มีลูกยาก

  • ฤกษ์ต่าง ๆ ทำให้ไม่มีบุตร เช่น
  • ฤกษ์เข้าอยู่ - ฤกษ์ซ่อมแซม - ฤกษ์ตั้งเตียง - ฤกษ์อื่น ๆ ....

หากเป็นทิศห้าม เช่น อสูร ทิศแตกสลาย ดาว 5 ก็เป็นสาเหตุสำคัญ ดังที่จะได้ยินกันบ่อย ๆ คือ ทุบซ่อมบ้านเพื่อเตรียมรับเด็ก และมักปรากฎว่า แท้ง พิการ เพราะฤกษ์ผิด

  • ข้อห้ามต่าง ๆ ในขณะตั้งครรภ์
  • บุญกรรม แต่ละคน

แนวปฏิบัติ สำหรับผู้ที่ไม่มีบุตร หรือมีลูกยาก

  • หากอายุไม่มาก ( ไม่เกิน 30 ปี ) ขอให้ลองแก้ทางหยางดูก่อน
  • ปรึกษาหมอ แพทย์แผนปัจจุบัน

แต่หลายคน ก็ได้บุตรเพราะแพทย์แผนจีน

2.ปรับเปลี่ยนการดำรงชีวิต

  • รักษาสุขภาพ ทานอาหารมีประโยชน์
  • งดเหล้า บุหรี่ อาหารไม่มีประโยชน์
  • ออกกำลังกาย พักผ่อนให้เพียงพอ และมีทัศนคติที่ดี

3.หมั่นทำบุญ สังฆทาน นั่งสมาธิ

  • เวลาขอ ให้ขอเฉพาะการมีบุตรที่ดี และครบ 32

4.หากข้างต้นไม่ได้ผล จึงค่อยพิจารณาแก้ฮวงจุ้ย

จากประสบการณ์ที่ผ่านมา สามารถแก้ได้ประมาณครึ่งหนึ่ง

กรณีศึกษา : น้องพิตต้า Pitta ( รูปข้างต้น )

เป็นลูกสาวของศิษย์ท่านหนึ่ง ซึ่งไม่มีบุตรมาเป็นเวลานาน รักษากับหมอทั้งแผนปัจจุบัน และแผนโบราณ

ภายหลังเมื่อวิเคราะห์ดวงจีน ก็พบว่าเป็นดวงมีบุตรยากทั้งคู่ ตลอดจน บ้านก็เป็นทิศทางล้มเหลว และหัวนอนก็ไม่ถูกต้องกับดวงจีน

เมื่อปรับทิศทางบ้าน เตียงนอน และปรับแก้ดวงจีนด้วยเหรียญ ครอบครัวนี้ก็สมบูรณ์ ได้ทารกหญิงเป็นเด็กน่ารักมาเป็นสมาชิก

จัดปรับพื้นที่และสถาปัตยกรรมตามหลักฮวงจุ้ย

ให้คำปรึกษาและวิเคราะห์พื้นที่จริงสำหรับบ้าน คฤหาสน์ ออฟฟิศ และวางตำแหน่งศาลเจ้าที่/ตี่จู้ โดยอาจารย์สุภชัย วิวัฒนะประเสริฐ
