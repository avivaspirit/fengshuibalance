  • ห้องควรสงบพอประมาณ 🥰

... ปราศจากเสียงดัง / การรบกวนของคนเดินเข้าออก ... เสียงรบกวนบางอย่างกลับดี เช่น … White noise คือ เสียงบำบัดสีขาว ... ฝนตก ... Air … เพลงบรรเลง Classic - Mozart / Beethoven ... จะทำให้มีสมาธิดี … Note : ปิดมือถือ / TV .

  • แสงสว่างที่เหมาะสม ✴

… และควรมีหน้าต่าง มีแสงธรรมชาติเข้ามาในห้อง … ( ห้องเป็น อิน / แสงสว่างภายนอกเป็น หยาง - สมดุล ) .

  • สีที่เหมาะกับการอ่านหนังสือ ( ตามหลักจิตวิทยา )

… สีเขียว ให้ความรู้สึกผ่อนคลาย สงบ 🆗 ... มีสมาธิ ความคิดสร้างสรรค์ดี … สีฟ้า ช่วยให้รู้สึกสงบ และมีสมาธิ … ( ทาเพียงผนังเดียวที่เห็นบ่อย ) .

  • อากาศถ่ายเท สะอาด 🎯

… แนะนำ ควรมีเครื่องฟอกอากาศ .

  • ใช้ Diffuser ปล่อยกลิ่นหอมบางเบา ช่วยเพิ่มสมาธิได้

… ลาเวนเดอร์: ช่วยให้รู้สึกผ่อนคลาย ลดความเครียด 🤩 … ส้ม: ช่วยกระตุ้นความคิดสร้างสรรค์ และทำให้รู้สึกสดชื่น … ยูคาลิปตัส: ช่วยให้รู้สึกกระปรี้กระเปร่า สมาธิ … โรสแมรี่: ช่วยเพิ่มความจำ และทำให้รู้สึกตื่นตัว … ชาเขียว: ช่วยให้รู้สึกสงบ และผ่อนคลาย .
