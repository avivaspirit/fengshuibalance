Think Twice : ห้องน้ำในห้องนอน

ซินแสบางคนมีห้ามห้องน้ำในห้องนอน อ้างว่าตำราโบราณห้ามไว้

ช้อเท็จจริง สมัยโบราณ ระบบสุขภัณฑ์ไม่ดีพอ มีกลิ่น และเป็นแหล่งเชื้อโรค จึงนิยมสร้างห้องส้วมนอกบ้าน แม้จะต้องเดินไกลสักหน่อย

สมัยปัจจุบัน มีความก้าวหน้าเทคโนโลยีมาก กำจัดกลิ่นได้ดี ใช้งานได้สะดวก สะอาด ปลอดโรค หลายแห่งตกแต่งอย่างสวยงาม อวดโชว์ได้

นึกถึงการใช้งานจริง ( หยาง ) ก็จะสะดวก ไม่ต้องออกนอกห้องนอน ไม่ต้องกังวลเรื่องความปลอดภัย ไม่ต้องกังวลความไม่เรียบร้อยของการแต่งกาย

>> สรุปแล้ว ห้องน้ำในห้องนอน ไม่ผิดหลักฮวงจุ้ยใด ๆ สำคัญที่ ตำแหน่งห้องน้ำ ถูกต้องกับดวงดาว 9 ยุคหรือไม่ ( อิน )

>> พึงระลึกไว้เสมอว่า ฮวงจุ้ยที่ดี หลักอิน ( วิชาการฮวงจุ้ย ) และหลักหยาง ( การใช้งานจริง ) ต้องสอดคล้องกัน จึงจะเป็นฮวงจุ้ยที่ดี

จัดปรับพื้นที่และสถาปัตยกรรมตามหลักฮวงจุ้ย

ให้คำปรึกษาและวิเคราะห์พื้นที่จริงสำหรับบ้าน คฤหาสน์ ออฟฟิศ และวางตำแหน่งศาลเจ้าที่/ตี่จู้ โดยอาจารย์สุภชัย วิวัฒนะประเสริฐ
