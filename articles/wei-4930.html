ทิศทางลม ในประเทศไทย จากกรมอุตุฯ

📅 วันที่: 2016-07-29 📂 หมวดหมู่: บ้าน (Home) 📈 ความนิยม: 0

💡 สรุปใจความสำคัญ: ทิศทางลม ในประเทศไทย จากกรมอุตุฯ 1. ลมมรสุมตะวันตกเฉียงใต้ ... กลาง พค - กลาง ตค. 2. ลมมรสุมตะวันออกเฉียงเหนือ ... กลาง ตค. - กลาง กพ. ... ( แล้วมีนา เมษา ลมมาจากทิศทางไหน ? ) ......

ทิศทางลม ในประเทศไทย จากกรมอุตุฯ

  • ลมมรสุมตะวันตกเฉียงใต้ ... กลาง พค - กลาง ตค.
  • ลมมรสุมตะวันออกเฉียงเหนือ ... กลาง ตค. - กลาง กพ.

... ( แล้วมีนา เมษา ลมมาจากทิศทางไหน ? )

*** ขอบคุณ คุณเอกวัฒน์ เอื้อเฟื้อข้อมูล แจ้งว่า

ช่วงมีนาคม - เมษายน เป็นลมตะเภา หรือ ลมว่าว ซึ่งลมพัดมาจาก ทิศใต้ หรือ ตะวันออกเฉียงใต้ ครับ

เราต้องเลือกเปิดช่องลมให้ถูกต้อง ลมจึงจะเข้าบ้าน หลักการทั่วไป

  • ลมจะเข้าได้ ต้องมีทางออก
  • เปิดในทิศทางลมผ่าน

นอกจาก บานหน้าต่างที่ยื่นดักลมแล้ว ผนังอาคารของบ้านที่ยื่นออกไป ก็เป็นตัวดักลมที่ดี ( ดังนั้น บ้านไม่จำเป็นต้องสี่เหลี่ยมทื่อ ๆ ขาดเสน่ห์ )

หลายท่านชอบต่อเติมหลังบ้าน ส่วนใหญ่ครัวไทย ขยายจนสุดพื้นที่ ส่วนใหญ่ 2 เมตร ตามกม.กำหนด กลายเป็นปิดทางลมเข้าออกจนหมด สิ่งที่เกิดขึ้น คือ ... -> ลมไม่เข้าบ้าน อากาศไม่ถ่ายเท -> มืด ( แสงอาทิตย์ไม่เข้า ) เหม็นอับชื้น เชื้อรา -> นั่งได้ไม่นาน -> ร้อน ติดแอร์ -> ค่าไฟเพิ่ม

ข้อแนะนำ

  • สังเกตุทิศทางลมของบ้านให้ดี

... ( ทดลองเปิดปิดประตู หน้าต่าง )

  • อย่าสร้างส่วนต่อเติมขวางทิศทางลมนี้

... อาจสร้างแค่มุมใดมุมหนึ่ง

Case Study 1 เคยแนะนำลูกค้าไปว่าอย่าทำเต็ม แต่ลูกค้ายืนยันจำเป็นต้องใช้พื้นที่ เพราะชอบทำอาหาร ได้ห้องครัวใหญ่ขึ้นจริง แต่สุดท้าย เจอกับปัญหาอับลม อึดอัดทนไม่ไหว ต้องทุบทิ้งไปส่วนหนึ่ง จึงดีขึ้น

Case Study 2 เจ้าบ้านตั้งใจจะทำเต็มชนกำแพงด้านหลังบ้าน เลยให้ด้านข้างด้านนึงเว้นห่างกำแพง 2 เมตร เช่น บ้านกว้าง 10 เมตร ครัวที่ต่อเติมกว้าง 8 ม. เพื่้อเป็นช่องแสง และช่องลม ให้อากาศไหลเข้า ส่วนอาคารที่ยาวกว่า 2 เมตร ใช้เป็นแผงดักลม ดึงลมให้เข้าบ้าน ลมไหลเวียนดี

เรื่องเหล่านี้ สถาปนิกรู้ดี แต่หลายท่านมองข้ามไป เน้นเรื่องความสวยงามแทน ล่าสุด เจ้าบ้านอีกรายบ่นให้ฟังว่า สถาปนิกออกแบบแผงบังแดดให้ที่ทิศเหนือ ซึ่งไม่จำเป็นเลย ให้ย้ายไปด้านทิศตะวันตกแทน

ภาพประกอบ เป็นการบริหารจัดการลม วางผิด ดักผิด ลมไม่เข้า ศึกษารูปแบบไว้ครับ มีประโยชน์มาก Credit : Club de Français - HAU
