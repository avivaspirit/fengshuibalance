โดยปกติ ตี่จู้ - เจ้าที่ จะต้องอยู่ชั้น 1 เท่านั้น แต่ลูกค้าท่านหนึ่ง ชาวสิงคโปร์ บอกว่า ที่ฮ่องกง และสิงคโปร์ ส่วนใหญ่จะตั้งเจ้าที่ใน Condo

ปีกอ่น ได้ไปจัดฮวงจุ้ยให้เขาซึ่งเปิด สนง.ในไทย อยู่บนชั้น 2 และเขายืนยัน ขอให้กำหนดตำแหน่งที่ตั้งเจ้าที่ให้ด้วย ( ถ้าไม่ตั้ง เขาจะรู้สึกไม่สบายใจ จึงต้องทำตามขอ ) ปัจจุบัน ธุรกิจก็ไปได้ดี

อาทิตย์ที่แล้ว ครอบครัวคนไทย ต้องการจะตั้งเจ้าที่ ใน Condo ขนาดใหญ่ แต่ด้านหลังเป็นหน้าต่าง จึงแนะนำให้ติดแผ่นหินอ่อน ขนาดใหญ่กว่าเรือน อยู่ด้านหลัง เป็นกำแพงให้ตัวเรือน และเลือกสีแผ่นที่เข้ม เพื่อขับเน้นตัวเรือนให้สวยเด่น

หากจะให้สวยสง่า และดูมั่นคงกว่านี้ เพิ่มแผ่นหินใหญ่อีกแผ่นซ้อนด้านหลัง ใหญ่เท่าเฟรมช่องหน้าต่าง สีเข้มกว่า เหมือนเป็น ภูเขาซ้อนกัน ( แผน่หลังสีเข้มกว่า เพื่อให้เห็นการซ้อนกันที่ชัดเจน ) จะทำให้สวยสง่า ดูมั่นคงกว่า

แต่ที่แปลกคือ วันนี้ คุณขจร ลูกค้าเก่าแก่ ต้องการตั้งเจ้าที่ ใน Condo ใหม่ เป็น Penthouse ห้องใหญ่ยกชั้น 2 Case ติด ๆ เลยมาเล่าสู่กันฟัง

Note : ซินแสมีหน้าที่กำหนดตำแหน่ง และฤกษ์ให้เจ้าบ้าน . ข้อมูลจาก FanPage หลายท่าน เล่าให้ฟังว่า มีซินแสบางคน กำหนดว่า ต้องให้เขาตั้งให้เท่านั้น จึงจะศักดิ์สิทธิ์ ( ไม่จริง ) เฉพาะค่าครูประกอบพิธี เรียก 20000 บางรายชื่อดัง เรียก 80000 พร้อมเครื่องเซ่นไหว้ ( แล้วก็ไม่มีอะไรดีขึ้น มีแต่แย่ลง ) . ขอ FanPage ทุกท่าน พึงใช้ "สติ" พิจารณาเสมอ . เจ้าที่ คือ วิญญาณที่สถิตอยู่ ณ สถานที่นั้น ๆ เรา - เจ้าบ้าน - ทำหน้าที่เชิญท่านเข้าเรือน ด้วยความเคารพ และตั้งใจ ... เจ้าที่ ท่านรับรู้ได้ หากตำแหน่ง ทิศทาง ฤกษ์ ถูกต้อง ท่านจะมีพลัง มีบารมี สามารถนำความเจริญรุ่งเรือง มาสู่ครอบครัวเราได้อย่างแน่นอน . โปรดลองใช้สามัญสำนึกตรองดู จะมีผู้ใดมีความตั้งใจในการเชิญท่าน มากกว่าเจ้าบ้านอีก ดังนั้น ข้าพเจ้าให้ลูกค้าทุกคน ตั้งเจ้าที่เองทั้งสิ้น ( Case ตัวอย่างลูกค้าทั้งหลายใน Page นี้ ก็เป็นเช่นนั้น ) . สรุป วันนี้ช่วยท่านประหยัดไปหลายหมื่นแล้วครับ :) Share ช่วยเพื่อนท่านประหยัดได้อีกมากเช่นกัน
