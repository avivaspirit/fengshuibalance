บันทึกฮวงจุ้ย (Fengshui Notes)

ซินแสรุ่นพี่อาวุโสท่านหนึ่ง

📅 วันที่: 2023-02-14 📂 หมวดหมู่: 📝 บันทึกฮวงจุ้ย · ⭐ ดวงจีน 📈 ความนิยม: 460

ซินแสรุ่นพี่อาวุโสท่านหนึ่ง ( จำรูปดวงเก่งมาก ดูครั้งเดียว จำได้เลย ) แวะมาทักทาย บอกว่า

ดวงผู้ใหญ่ลื้อ ปีที่ผ่านมา ไม่ดีนะ บอกไปว่า ปกติดี

แกบอกว่า เฮ้ย ! เป็นไปไม่ได้ ทบทวนดูทีสิ หันไปถามย้ำภรรยา ก็ได้รับคำตอบว่า แข็งแรง ปกติดี งงหนักมาก ‼ บอกไม่น่าผิดพลาด

อันที่จริง แกทายถูกต้องหมด แต่เราผ่อนหนักเป็นเบา ด้วยวิชาการความรู้หลากหลาย

สรุป คือ ใช้ตัวช่วยหลากหลาย 🚩

  • พกเหรียญปรับแก้ดวงประจำ
  • หันทิศหัวนอนปรับธาตุให้สมดุล
  • ใช้แท่ง Reiki แดง 🔴 เพื่อให้หลับลึก

( หลับลึก จะช่วยซ่อมแซมร่างกายได้ดี )

  • ออกกำลังกาย หาหมอตามกำหนด
  • ทำบุญตามเหมาะสม
  • นั่งสมาธิ ขอพรสุขภาพ ตามฤกษ์พิเศษ

ถ้าท่านทำตามแนะนำ สุขภาพดีกว่าเกณฑ์แน่นอน 🥰

จัดปรับพื้นที่และสถาปัตยกรรมตามหลักฮวงจุ้ย

ให้คำปรึกษาและวิเคราะห์พื้นที่จริงสำหรับบ้าน คฤหาสน์ ออฟฟิศ และวางตำแหน่งศาลเจ้าที่/ตี่จู้ โดยอาจารย์สุภชัย วิวัฒนะประเสริฐ
