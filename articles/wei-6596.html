อาจารย์แม่ ( ภรรยา อ.เกรียงไกร ) ท่านเป็นผู้มี Sense ... ท่านแนะนำว่า คนที่ดวงตก ใบหน้าหมองคล้ำ ไม่มีราศี ... ( Aura หม่น ) แล้วเกิดเหตุไม่ดีบ่อย เคราะห์ซ้ำกรรมซัด . ให้บีบมะนาว เอาน้ำมะมนาวมาล้างหน้า ... ทิ้งไว้นิดนึง ( ประมาณให้มันชำระล้าง ) ... อย่าทิ้งไว้นาน จะแสบ 😂 . แล้วล้างน้ำสะอาดตาม ... จากนั้นไปทำบุญ กรวดน้ำ ( หรือจะทำก่อนก็ได้ ) ... เคราะห์จะเบาบางลง 🚩
