ตัวอย่างการออกแบบภายนอกที่ดี ... พื้นที่ลูกค้า หน้ากว้างมาก ด้านลึกไม่มากนัก หากทำประตูบ้านไม่เด่น จะถูกภาพรวมกลืนไปหมด

เจ้าบ้านส่งแบบมาให้พิจารณา จะเห็นได้ว่า ประตูบ้านหลักชัดเจน มีโถงนอกสูงใหญ่ มีความโดดเด่น ภูมิฐาน ออกแบบได้สวยงาม ถูกต้องครับ มีทางลาดสำหรับรถเข็นผู้สูงอายุ นับว่ารอบคอบดีมากครับ

สำหรับ ขั้นตอนการทำงานของเรา

  • วัดองศาพื้นที่จริง สำรวจชัยภูมิโดยรอบ

... แนะนำวิธีการปรับแก้เบื้องต้น

  • กำหนดจุดสำคัญ ได้แก่ ตำแหน่งประตูรั้ว

... ประตูอาคาร ประธาน ห้องครัว/เตา ... โรงจอดรถ สีอาคาร ฯลฯ ... ( ศาลตายาย / ศาลพระภูมิ กรณีจำเป็น ) ... โดยพิจารณาร่วมกันชัยภูมิ ดวงดาว ... และสะดวกในการใช้สอย ความสวยงาม

  • วิเคราะห์ดวง และกำหนดทิศหัวนอน

... ตำแหน่งห้องน้ำ ประตู ฯลฯ

  • เจ้าบ้านนำแบบคุยกับสถาปนิก Interior
  • นำแบบมาตรวจ กำหนดรายละเอียดเพิ่มเติม

... Air Coil ร้อน ( ตำแหน่งน้ำพุ หากต้องการ )

  • ให้ฤกษ์กระทบดิน / แนะนำพิธีกระทบดิน
  • เมื่อใกล้เสร็จ ให้ฤกษ์เข้าอยู่

... แนะนำขั้นตอนพิธีเข้าอยู่ .
