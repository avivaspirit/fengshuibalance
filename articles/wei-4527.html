ปี 2565 ราศี ยิ่ม / เอี้ยง ( 9/3 ) หรือ น้ำ / ไม้ . ดิน พิฆาต น้ำ ( น้ำ เป็นโชคลาภของ ดิน ) ทอง พิฆาต ไม้ ( ไม้ เป็นโชคลาภของ ทอง ) . ดังนั้น คำตอบ คือ ดิถี ( วันเกิดราศีบน ) เป็น ดิน หรือ ทอง 🚩 . แล้วได้ลาภจริงหรือ ? ... ดูดวงตัวอย่างแนบ . วันเกิดธาตุดิน ( - คือ พลังอิน และ + คือ พลังหยาง ) ราศีปีจร 2565 เป็น น้ำ/ไม้ ... ปีนี้ได้ลาภ 🤩 . แต่เมื่อปีนี้ เป็นปีเสือ ดวงเกิดเดือนวอก ชง เสือ ... ไม่ได้ลาภ 😅 ... หนำซ้ำ เกณฑ์อุบัติเหตุอีก เกิดเรื่องไม่คาดฝัน ... หลักเดือน ยังหมายถึง ผู้ใหญ๋ ... ชง จึงถูกกระทบด้วย ( เกณฑ์ป่วยไข้ เกิดเหตุ ) ... ปีนี้ สำหรับดวงนี้ จึงไม่ใช่ปีที่ดี 😱 .
