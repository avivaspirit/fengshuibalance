บันทึกฮวงจุ้ย (Fengshui Notes)

แนะนำ วิธีการปรับปรุงการตั้งพระ

📅 วันที่: 2017-11-11 📂 หมวดหมู่: บันทึกฮวงจุ้ย (Fengshui Notes) 📈 ความนิยม: 0

💡 สรุปใจความสำคัญ: แนะนำ วิธีการปรับปรุงการตั้งพระ . 1. ฐานโปร่งใส ไม่มั่นคง ... การแก้ไขด้วยกระดาษ ( ฉีกขาดได้ ) ... หรือผ้า ( เลื่อนไปมาได้ง่าย ) ... ใช้แผ่นไม้บางปูทับกระจก ดีที่สุด . 2....

แนะนำ วิธีการปรับปรุงการตั้งพระ .

  • ฐานโปร่งใส ไม่มั่นคง

... การแก้ไขด้วยกระดาษ ( ฉีกขาดได้ ) ... หรือผ้า ( เลื่อนไปมาได้ง่าย ) ... ใช้แผ่นไม้บางปูทับกระจก ดีที่สุด .

  • ถ้วยแก้วน้ำสูงไป บังองค์ท่าน

... ทำให้ไม่เด่นสง่า ... เปลี่ยนเป็นเตี้ยลง .

  • ดอกไม้สด เมื่อเหี่ยวแล้วให้ทิ้ง

... เปลี่ยนเป็นดอกไม้ปลอมแทน ... หรือเป็นพวงมาลัยปลอม ... มีเพียงอย่างใดอย่างหนึ่งพอ .

  • ฐานรอง ไม่จำเป็นต้องมี

... ยกเว้น องค์เล็กกว่าภาพรวม ... กรณีมีพระหลายองค์ ... เสริมแท่นองค์ประธาน ... จะทำให้สูงใหญ่ เด่นสง่า . ตอบถูกกันเป็นส่วนใหญ่ครับ . การจัดตั้งวางพระ สิ่งศักดิ์สิทธิ์ ให้ถูกต้องตามหลักฮวงจุ้ย https://goo.gl/VJXj3z

จัดปรับพื้นที่และสถาปัตยกรรมตามหลักฮวงจุ้ย

ให้คำปรึกษาและวิเคราะห์พื้นที่จริงสำหรับบ้าน คฤหาสน์ ออฟฟิศ และวางตำแหน่งศาลเจ้าที่/ตี่จู้ โดยอาจารย์สุภชัย วิวัฒนะประเสริฐ
