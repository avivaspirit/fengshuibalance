เฉลย .... สิ่งใดคือประธาน ( จุดเด่น ) ของบ้าน A. กรอบรูปเหนือชุด Computer B. ฮกลกซิ่ว C. กรอบรูปในหลวง D. ไม่มีสภาพชัดเจน ... คำตอบ D ไม่มีสภาพชัดเจน ... หากเราดูคำตอบของส่วนใหญ่ จะพบว่าไม่มีจุดเด่นชัด แม้ประธานที่มีแนวโน้มเด่นสุด คือ ฮกลกซิ่ว กลับไม่ชัดเจน 1. มีจุดแย่งสายตามาก 2. อยู่ตรงกลางหลังบ้านจริง แต่เป็นหน้าต่าง ... แม้จะมีม่านช่วย ด้านหลังก็ยังโปร่งแสงอยู่ 3. วางบน TV แย่งความเด่นไปอีก 4. หาก TV เป็นโต๊ะเตี้ยเรียบ ๆ ฮกลกซิ่ว จะเด่นขึ้น ... และหากมีฉากหลัง จะถือว่าเด่นใช้ได้ ... ถ้าตอนซื้อ ได้องค์ใหญ่กว่านี้อีกสักนิด จะดูดีกว่า ... ประธาน คือ จุดสำคัญของบ้าน ต้องเห็นเด่นชัด ขนาดใหญ่เหมาะสม มีความชัดเจน ด้านหลังต้องนิ่ง มั่นคง ... บารมี จึงจะดี . ลองไปสังเกต โรงแรมสวยใหญ่ เมื่อเดินเข้าประตูหลัก จะพบกับโถงสูงใหญ่ "โปรงโล่ง กว้าง สว่าง สะอาด และเป็นระเบียบ" . หลังจากนั้น คุณจะเห็น Counter ชัดเจน เพราะเจ้าของก็ต้องการให้แขกมาติดต่อได้ง่าย และส่วนใหญ่ก็จะตกแต่งให้หรูหรา ดูดี ภูมิฐาน . . ....... เนื้อหาดี มีประโยชน์ โปรดช่วย Share ... อ่านสาระฮวงจุ้ยอย่างมีแนวคิด ✔ กด Like เพจ ✔ กดติดตาม เลือก "See First / เห็นก่อน" ( นโยบายใหม่ Facebook ท่านจะเห็นเราน้อยมาก ) ( ยกเว้น กดเลือก See First ) ------------------------- Fengshui Balance ให้คำปรึกษาด้านฮวงจุ้ย ( ชัยภูมิ ทิศทาง ดวงจีน ฤกษ์ ) อย่างครบถ้วนถูกต้อง และเป็นระบบ สอดคล้องกับแบบสถาปัตย์ และการใช้งานจริง ( ลองศึกษา Post ผลงานที่ผ่านมาดูก่อนครับ ) ปรึกษาได้จนจบงาน ( Turnkey Project ) ติดต่อ : inbox Line ID : suppachaibig Line PC : http://line.me/ti/p/twX0_SxVSX
