ท่านเจ้าบ้านได้เชิญให้ไปวิเคราะห์บ้านพักอาศัย

📅 วันที่: 2016-01-11 📂 หมวดหมู่: ดวงจีน (Destiny) · บ้าน (Home) 📈 ความนิยม: 0

💡 สรุปใจความสำคัญ: ท่านเจ้าบ้านได้เชิญให้ไปวิเคราะห์บ้านพักอาศัย จากการแนะนำของเพื่อน ซึ่งทางเราได้ปรับแก้ฮวงจุ้ยโรงงาน แล้วได้ผลดี - ดู Post เดิม - Clip น้ำพุ ... ภาพรวมภายนอก สะอาดเรียบร้อย...

ท่านเจ้าบ้านได้เชิญให้ไปวิเคราะห์บ้านพักอาศัย จากการแนะนำของเพื่อน ซึ่งทางเราได้ปรับแก้ฮวงจุ้ยโรงงาน แล้วได้ผลดี - ดู Post เดิม - Clip น้ำพุ ... ภาพรวมภายนอก สะอาดเรียบร้อย มีระเบียบ Modern เราจะมองเห็นโรงรถและประตู มองไม่เห็นด้านในตัวบ้าน บ่งบอกถึง ความเป็นระเบียบวินัย และต้องการความเป็นส่วนตัว ... สิ่งแรกที่เปิดเข้าไป จะพบ องค์กวนอูขี่ม้าถือทวน หันมาหน้าประตู หลังประตูเป็น ตี่จู้หินอ่อน กำแพงทึบ นิ่งมั่นคง ในแง่ชัยภูมิคือดี และฮกลกซิ่ว พิงกระจกใส ด้านหลังมองทะลุเห็นสวน คนเดินไปมา ขาดความโดดเด่น และมั่นคง รวมถึง วางองค์สลับที่กัน ( ศึกษาคำแนะนำจาก Post เดิม ๆ ) ... ห้องโถงใหญ่ โปร่งกว้าง บานกระจกรอบด้าน เห็นสระน้ำ และสวนเขียวขจี ลมพัดผ่านเบา ๆ ร่มรื่น ผ่อนคลาย สบาย น่านั่ง

*** เป็นหนึ่งในห้องรับแขกที่จัดบรรยากาศดีเยี่ยม ***

ด้านหลัง Sofa ใหญ่เป็นโต๊ะทานอาหาร โดยปกติแล้ว ควรแยกส่วนกัน เพื่อให้ความเรียบร้อย ในกรณีคนในบ้านกำลังทานอาหาร และมีแขกมาเยี่ยม จะได้ไม่เกิดความกระอักกระอ่วนต่อกัน ... ด้านหลัง โต๊ะทานอาหารเป็น Microwave ดีที่ไม่ได้อยู่ตรงกลาง ซึ่งเป็นตำแหน่งประธานบ้าน ... ถัดออกไป ซ้ายมือเป็นสระน้ำ และอาคารต่อเนื่อง หลังอาคารด้านนอก เป็นคลองของหมู่่บ้าน เงียบสงบ เนื้อที่สวนด้านหลังกว้างใหญ่ ทำให้มีระยะลมพัดเข้าอาคารได้ดี นำพาอากาศบริสุทธิ์เข้าสู่ตัวบ้าน เป็น "กระแสชี่" ที่ดี เหล่านี้ล้วนทำให้สุขภาพสมบูรณ์ แข็งแรง

หลังจากดูชัยภูมิรอบบ้าน ให้คำแนะนำปรับปรุงเบื้องต้นไป ทำการวัดองศาบ้าน เพื่อวิเคราะห์บทบาทดาว ผลปรากฎว่า องศาไม่ค่อยดีเท่าไร ด้านหน้าประตูอาคารเป็น ตำแหน่งเสียเงิน ( แต่ยังไม่ใช่ตัวเลวร้ายระดับวิบัติ ) รวมถึง ตี่จู้ อยู่หลังประตูอีกบานที่ไม่ค่อยได้เปิดใช้ การเสียเงิน จึงไม่หนักหนามากนัก มีค่าใช้จ่ายเยอะ ... ตำแหน่งภายในห้องรับแขก ประตูเข้าห้องดีมาก สระน้ำ ก็เป็นตำแหน่งโชคลาภที่ดี มาเสียที่ตำแหน่ง ที่เปิดให้ประตูกระจกให้ลมพัดผ่าน เป็นตำแหน่งเสียเงิน กรณีนี้ แก้ง่ายมาก เพราะกำแพงฝั่งนี้เป็นประตูกระจกหมด ให้ปิดประตูเสียลาภนี้ และเปิดประตูกระจกอีก 3 บานถัดไปแทน ถึงตรงนี้ สรุปเบื้องต้นได้ว่า เข้าอยู่อาศัยแล้ว มีค่าใช้จ่ายมาก เจ้าบ้านบอกว่า ถูกต้อง

จากนั้น วิเคราะห์ดวงจีนเจ้าบ้านชาย เป็นคนมีระเบียบวินัยสูง สอดคล้องกับการจัดบ้าน ( สะอาด เป็นระเบียบ เรียบร้อย ) สุขภาพที่ต้องระวัง : ความเครียด และขา เป็นผู้คุมโรงงาน ดูแลการผลิต เจ้าบ้านหญิง เป็นดวงบัณฑิต ปัญญาดี ค้าขายเก่ง ดูแลฝ่ายขายภายใน และภายนอกประเทศ สุขภาพ : ธาตุไฟ อ่อนแอไปเล็กน้อย สรุป ทั้ง 2 เลือกทำงานได้เหมาะกับดวงชะตาดีแล้ว

ส่วน Update เพิ่มเติม

หลังจากวิเคราะห์ดวงอย่างละเอียดแล้ว กำหนดทิศหัวนอนใหม่ เพราะตำแหน่งประตูเดิมแย่มาก ปรับทิศหัวนอนใหม่ ตำแหน่งที่ดีที่สุดในแง่ฮวงจุ้ย กลับใช้สอยไม่สะดวก และมีการปรับแก้เยอะ จึงเลือกอันที่รองลงมา ปรากฎว่า เหมาะสมมาก ตำแหน่ง Air ห้องน้ำ ประตู ลงตัวหมด ไม่ต้องทุบแก้เลย

ห้องนอนลูก ๆ ดีอยู่แล้ว ปรับรายละเอียดเพิ่มเติมเล้กน้อย หลังจากเดินสำรวจอีกรอบ แลกความเห็นกับเจ้าบ้าน ชั้นล่างให้ปรับเพิ่มเดิม คือ

  • องค์กวนอู ถือง้าว ไม่เหมาะกับบ้าน โดยเฉพาะมีเด็กเล็ก

... จึงดูฤกษ์ให้ย้ายไปบูชาที่ Office แทน

  • ตำแหน่งเจ้าที่เดิม หากตั้งตรงประตู จะเสียลาภมาก

... ( ไม่ใช่กฎตายตัวว่า ต้องตั้งให้ตรงประตูเสมอไป ...... ขึ้นกับบทบาทของดวงดาว และองค์ประกอบอื่น ๆ ) .... แม้ปัจจุบัน จะหลบอยู่หลังประตูที่ไม่ค่อยได้เปิด .... แต่ก็ตรงกับประตูรั้ว .... แนะนำให้ย้ายไปตั้งในตำแหน่งใหม่ เสริมบารมีเจ้าบ้าน Note : เดิมเป็นเรือนสีขาว พิงกำแพงขาว จึงดูกลืนกันเกินไป ไม่โดดเด่น ตำแหน่งใหม่ที่ย้ายไป สีเข้มขึ้น จึงโดดเด่น มีสง่าราศี และให้ตั้งฮกลกซิ่ว ให้ถูกต้อง

จัดปรับพื้นที่และสถาปัตยกรรมตามหลักฮวงจุ้ย

ให้คำปรึกษาและวิเคราะห์พื้นที่จริงสำหรับบ้าน คฤหาสน์ ออฟฟิศ และวางตำแหน่งศาลเจ้าที่/ตี่จู้ โดยอาจารย์สุภชัย วิวัฒนะประเสริฐ
