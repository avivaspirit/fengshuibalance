💡 สรุปใจความสำคัญ: ตั้งแต่ 4 กพ. 2559 - 3 กพ. 2560 เป็นปีวอกเต็มตัว ตามระบบโหราศาสตร์จีน ( นับแบบสุริยคติ ) ไม่ใช่ตรุษจีน ตามความเข้าใจของคนทั่วไป ( แบบจันทรคติ ) ... บุคคลที่เข้าข่าย ชง-ปะทะ ได้แก่...

ตั้งแต่ 4 กพ. 2559 - 3 กพ. 2560 เป็นปีวอกเต็มตัว ตามระบบโหราศาสตร์จีน ( นับแบบสุริยคติ ) ไม่ใช่ตรุษจีน ตามความเข้าใจของคนทั่วไป ( แบบจันทรคติ ) ... บุคคลที่เข้าข่าย ชง-ปะทะ ได้แก่ ท่านที่เกิด ปีเสือ ( ถ้าเกิด มค. จะเป็นนักษัตรปีที่ผ่านมา ) หรือ เดือนเสือ ( 4 กพ. - 5 มีนา ) หรือ วันเสือ ( ต้องเปิดปฏิทินจีน ) หรือ ยามเสือ ( 03.00 - 04.59 )

*** อื่น ๆ ไม่เรียกว่า ชง และไม่มี ชง 75 50 25 ***

ท่านที่เกณฑ์ ชง - ให้ระวังการเดินทาง บาดเจ็บ และเกิดเรื่องไม่คาดฝัน ( กรณีเบา เสียเงินทอง ) การปรับแก้ไขดวงชะตา

  • หมั่นทำบุญสังฆทาน
  • มี "สติ" อยู่แสมอ
  • ใช้เหรียญปรับแก้ดวงชง ในหนังสือปฎิทินฤกษ์มงคล 2559

หน้า 100 จะมีวิธีการพกอย่างละเอียด ... ช่วยผ่อนหนักเป็นเบาได้ ( ขออภัย ภาพประกอบไม่ Update ตามเหรียญที่แจกในเล่ม )

ทิศที่ต้องระวัง ห้ามกระทบ ( ทุบ เคาะ เจาะ ตอก ) ย้ายเข้าอยู่ ได้แก่ หลังบ้านทิศใต้ ( 135 - 225 องศา ) และ ทิศตะวันออกเฉียงเหนือ ( 22.6 - 67.5 องศา ) กรณีจำเป็น สามารถใช้ฤกษ์ปลอดภัยในหนังสือ หน้า 56 ได้

ทิศ "หน้าบ้าน" ที่ดี ประจำปี 2559 หน้าบ้าน ... ทิศตะวันออก ... จะมีข่าวดี เรื่องน่ายินดี แต่งงาน หน้าบ้าน ... ทิศตะวันตกเฉียงใต้ ... จะมีโชคลาภที่ดี หน้าบ้าน ... ทิศตะวันตก ... เด่นด้านการศึกษา สอบได้

ทิศ "หน้าบ้าน" ที่ต้องระวัง หน้าบ้าน ... ทิศเหนือ ... ระวังขโมย ของหาย หน้าบ้าน ... ทิศตะวันออกเฉียงเหนือ ... ติดขัด การค้าสะดุด การแก้ไข .. ตามหน้า 80 เป็นต้นไป
