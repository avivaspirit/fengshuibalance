ฤกษ์พิเศษสำหรับขอพร ------------------------------ วันวิสาขบูชา พุธ 6 พค. .... 15.30 น. 🚩 . A. ให้ทำบุญก่อน โดยการโอนเงินไปทำบุญ ... ( ทำได้ตั้งแต่เช้า ) ... เหมาะสุดเวลานี้ คือ บริจาคให้โรงพยาบาล ... ท่านที่ไม่ได้ทำมานาน แนะนำทำสัก 3 แห่ง ... กรวดน้ำด้วย อุทิศให้เจ้ากรรมนายเวร ด้วยจิตเมตตา ... และให้พ่อแม่ ครูอาจารย์ ท่านเจ้าที่ เทวดาผู้คุ้มครอง . B. 15.30 ... สวดมนต์ ไหว้พระ 💥 ... ถวายส้ม 3 ใบ + น้ำ ... ( + พวงมาลัยมะลิ หรือดาวเรือง ได้ยิ่งดี ) ... ไม่ต้องจุดธูป ให้ไหว้อย่างตั้งใจ ... 1 ชุด ไหว้ร่วมกันได้ทุกคน . ... ให้นึกถึงบุญกุศลที่ได้ทำมา ( อาจเปิดดูภาพในมือถือ ) ... เช่น ร่วมสร้างพระประธาน / ถวายเพล หลวงพ่อวิชชา ... บริจาคเลือด / เลี้ยงเด็ก วัดดอนจั่น ... ฯลฯ ... ยิ่งเกิดปิติ ขนลุกยิ่งดี ... แผ่บุญให้กับเจ้ากรรมนายเวรด้วยจิตที่เมตตา . C. 15.45 นั่งสมาธิ ( ในห้องที่สงบ ) ... นั่งพิง SE … หันหน้าไป NW ( ตกเฉียงเหนือ ) *** ... ( ใช้เข็มทิศในมือถือช่วย ) ... นั่งอย่างน้อย 30 นาที ให้ดี 45 นาที . 16.30 นั่งอยู่ที่เดิม 🔺 แล้วให้ขอพร ( เลือกเพียง 1 ) ดังนี้ 🎉 ---------------------------------------------------- 🧧🧧🧧 ใช้ได้ในเรื่องที่ดีเท่านั้น 🧧🧧🧧 ---------------------------------------------------- 1. ธุรกิจ การเงิน เจริญเติบโต ก้าวหน้า ... ปิดการขายได้ / เริ่มธุรกิจเสริม ... ที่ติดขัด ขอให้อุปสรรคคลี่คลาย . 2. ได้โอกาสที่ดี ผู้ใหญ่สนับสนุน ... เจรจาสำเร็จลุล่วง / ขอเงินกู้ธนาคาร . 3. ปัญญา เพื่อเรียนรู้ เพิ่มทักษะ ...
