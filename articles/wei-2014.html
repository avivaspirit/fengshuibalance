Boss จีนถามว่า ปกติ เขาเห็นอยู่ด้านหน้า ... เลยต้องเทียบแต่ละจุดให้เข้าใจ ... บางจุดใกล้ บ่อบำบัด มีกลิ่น ... ตั้งไม่ได้ . แต่จุดที่ให้ตั้ง ( อิน ) ... ตรงกับถนนทางยาวมาก ( หยาง ) ...
