ซินแสฮวงจุ้ย กรุงเทพ: ฝั่งตรงข้ามเป็นสิงห์

📅 วันที่: 2017-02-23 📂 หมวดหมู่: 🏪 ร้านค้า 📈 ความนิยม: 3,767

ฝั่งตรงข้ามเป็นสิงห์

  • ต้องแก้อะไรไหม ? 2. ต้องแก้อย่างไร ?

เฉลย

  • ระยะห่างสิงห์ถึงประตูร้านห่างมาก

... ( ถนน 4 เลน + เกาะกลาง + สิงห์ตั้งลึกถอยเข้าไป ) ... และมีกระแสรถวิ่งผ่านตลอด ... ผลกระทบด้านฮวงจุ้ยไม่มี .

  • แต่สำหรับคนที่กลัว ระแวง

... เรียกว่า มีผลทางด้านจิตวิทยา ... แม้จะอธิบายอย่างไร ก็ยังรู้สึกไม่สบายใจ ... ดังนั้น ... จึงจำเป็นต้องมีแก้ไขให้คนกลุ่มนี้สบายใจ ... ( ว่าได้แก้ ) ... บ่อยครั้ง เป็นช่องทางเสียเงิน ... บางรายเสียเงินมากมาย หลักหมื่น-แสนก็มีบ่อย .

จึงขอแนะนำดังนี้ การแก้ไขใด ๆ ต้องอยู่บนพื้นฐานดังนี้

  • ประหยัด ( หลักร้อย - หลักพันเกินพอแล้ว )
  • มีเหตุมีผลในการแก้ มีที่มาที่ไป

... เน้นหลักการ "เปลี่ยนศัตรูเป็นมิตร"

  • แก้แล้ว ต้องสวย ดูดี เข้ากับสภาพแวดล้อม

... ยิ่งดูไม่ออกว่ามีการแก้ ... ยอดเยี่ยม !!

  • แก้แล้ว ไม่ทำให้ผู้อื่นเดือดร้อน

... เช่น กระจกเงา บอลกระจก อาจสะท้อนรบกวนผู้อื่น

. การแก้ไข กรณีนี้ แนวคิด ปกติ สิงห์จะเล่นบอล และเล่นกับลูก

  • ลูกบอลกลม อาจแต่งเป็นหัวเสาประตู
  • ตั้งสิงห์ตัวเล็ก ๆ น่ารัก 2 ตัว ซ้ายขวาประตู

... วางพื้น ( บริวารต้องอยู่ที่ต่ำ ) ... ขนาดเล็กกว่าฝั่งตรงข้ามมากกว่าครึ่ง ... ฝั่งตรงข้ามเป็นพ่อแม่ ย่อมต้องมาดูแลลูก ... หลักการ "เปลี่ยนศัตรูเป็นมิตร" ... ของปรมาจารย์ เกรียงไกร บุญธกานนท์

NOTE : ตั้งสิงห์ควรดูฤกษ์ ติดบอล หากไม่มีการกระทบ ไม่ต้องดู . ผู้ใด มีประเด็นเสริม เพิ่มเติม เชิญเลยครับ .

จัดปรับพื้นที่และสถาปัตยกรรมตามหลักฮวงจุ้ย

ให้คำปรึกษาและวิเคราะห์พื้นที่จริงสำหรับบ้าน คฤหาสน์ ออฟฟิศ และวางตำแหน่งศาลเจ้าที่/ตี่จู้ โดยอาจารย์สุภชัย วิวัฒนะประเสริฐ
