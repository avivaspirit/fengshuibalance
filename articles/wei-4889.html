เฉลยการบ้าน #ฮวงจุ้ยออฟฟิศ

สำนักงาน Office สร้างบนน้ำ

ในแง่ความเป็นจริง

  • ความชื้นสูง ปัญหาเรื่องความอับชื้น กลิ่น เชื้อรา

... ปัญหาสุขภาพระบบทางเดินหายใจ

  • หากน้ำสกปรก จะเป็นแหล่งเชื้อโรค ยุง กลิ่นเหม็น
  • ปัญหาเรื่องความแข็งแรงของเสาอาคาร
  • ประตูหน้าที่ดูดี แต่กลับไม่มีการเปิดใช้

... ไปใช้ประตูด้านข้างที่สะดวกกว่า ... มองอีกมุมหนึ่ง ควรออกแบบให้ประตูหน้า ... อยู่ตำแหน่งที่สะดวกใช้งานจะดีกว่า

ในแง่ฮวงจุ้ย

  • ในแง่ชัยภูมิ ถือว่าล้มเหลว ไม่มีความมั่นคง

... เพราะเป็นน้ำล้อมรอบทั้งหมด

  • สภาพแวดล้อม ล้วนมีผลต่อจิตใจ

... บรรยากาศแม้ดูเป็นธรรมชาติ ... แต่หากน้ำเสีย มียุง หรือมีกลิ่น มีเชื้อรา ... ทำให้เราเกิดอารมณ์หงุดหงิด เบื่อหน่าย ... เหล่านี้ มีผลต่อผู้ใช้งาน ถือเป็นฮวงจุ้ยไม่ดีเช่นกัน

  • ในระบบดวงดาว 9 ยุค

... ดาวบารมีลงน้ำ บารมีหมดสภาพล้มเหลว ... ไม่สามารถรับลาภได้ ได้มาก็เสียไป ... นอกจากนี้ ดาวลาภวิบัติ ลงน้ำ มีแต่เรื่องเสียเงิน ... ( แม้ลาภวิบัติจะเข้าสู่ศูนย์กลาง แต่เมื่อเจอน้ำ ผลลบรุนแรง )

สรุป ผลงานไม่เป็นไปตามเป้าหมาย มีปัญหามาก

การแก้ไข : เนื่องจากสภาพชัยภูมิ ไม่เอื้ออำนวยในการแก้ไขใด ๆ จึงให้ห้องนี้เป็นห้องพักผ่อน นั่งเล่นของพนักงานแทน

แล้วให้ย้าย Office ไปอยู่บนบก สภาพแวดล้อมดูดีกว่า สะดวกในการใช้งานมากกว่า

การจัดฮวงจุ้ยรอบนี้สะดวกกว่าเดิมมาก เพราะการวางแบบแต่แรก ง่ายกว่าแก้ไขของเดิมที่มีข้อจำกัด จัดแบบแปลนด้านในได้สวยลงตัว สะดวกกับการใช้สอยจริง องศาอาคารดีมาก ประตูสามารถดึงกระแสโชคลาภได้ดี สุดท้าย กำหนดตำแหน่งห้องผู้บริหาร และผู้จัดการ อยู่หลังสุด จัดทิศนั่งทำงาน ทิศตั้งพระ หนุนเสริมดวงชะตาผู้บริหาร กำหนดฤกษ์กระทำ เป็นขั้นตอนสุดท้าย

เชื่อว่า ที่นี่จะเห็นความแตกต่างจากเดิมมากพอควร ด้วยของเดิมติดลบมาก และทำเลใหม่ติดบวกมาก

Fengshui Balance สอนให้ใช้เหตุผล ตรรกะนำ แล้วจึงใช้หลักวิชาฮวงจุ้ยประกอบอธิบายเพิ่มเติม แม้บางอย่างอาจไม่สามารถอธิบายด้วยเหตุผลได้ทั้งหมด แต่อย่างน้อย ท่านจะมีเหตุมีผลในการเชื่อ ปฎิบัติ

Fengshui Balance ให้คำปรึกษาด้านฮวงจุ้ยอย่างครบถ้วนถูกต้อง และเป็นระบบ สอดคล้องกับแบบสถาปัตย์ และการใช้งานจริง ( ลองศึกษา Post ผลงานที่ผ่านมาดูก่อนครับ ) ปรึกษาได้จนจบงาน ( Turnkey Project ) ติดต่อ : Line http://line.me/ti/p/twX0_SxVSX
