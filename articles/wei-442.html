2560 หน้าบ้านทิศใต้ จะติดขัดมีอุปสรรค สรุป ทุกประเด็นคำถาม กรุณาอ่านหลาย ๆ รอบ ก่อนจะตั้งคำถาม

4 กพ. 2560 - 4 กพ.2561 ปีนักษัตร "ระกา" ทิศใต้เป็นทิศที่ ดาว 5 เบญจภูติมาสถิตอยู่ ห้ามกระทบกระเทือนใด ๆ . นอกจากนี้ หากประตูเป็นทิศใต้ การค้าจะสะดุด ติดขัด ไม่ราบรื่น นาน 1 ปี ( แม้ประตูจะเป็นดาวโชคลาภก็ตาม ) . ตอนนี้ ที่รับแจ้งมา

  • แท้ง 2 ราย
  • คนในบ้านป่วยตลอด
  • ธุรกิจติดขัด จำนวนมาก
  • ลูกค้าลดลง แบบสังเกตุได้
  • ลูกค้าเข้ามา แต่ปิดการขายได้น้อย
  • จัดบูทออกงาน ขายแทบไม่ได้เลย
  • พนง.ปั่นป่วน ลาออกกระทันหัน

. การแก้ไข จุดสำคัญ คือ ประตูรั้ว และประตูบ้าน หน้าต่างไม่เกี่ยว .

  • ครั้งแรก ให้ราดน้ำ 5 ขัน ติดต่อกัน 5 วัน

... ( ไม่ต้องดูฤกษ์ / ยิ่งเร็วยิ่งดี ) ... หากประตูเป็นทิศ"เฉียงใต้" ไม่ต้องแก้ ... แต่หากจะแก้ก็ได้ ไม่มีข้อเสีย ... ราดลงที่พื้นหน้าประตู ... สถานที่เล็กใช้แก้วเล็ก / สถานที่ใหญ่ใช้ ขัน .

  • ต่อไป ราดน้ำทุกต้นสัปดาห์ ( วันไหนก็ได้ )

... ราดจนถึง 4/2/2561 .

  • ติดกั้ว "ดาว 1" / ต้องดูฤกษ์

... กรุณาอ่าน หน้า 86 - 87 ( อ่าน 2 รอบ ) *** ... "กั้วดาว 1" ตัดจากท้ายเล่ม ติดกับปกหลังด้านใน ... หนังสือปฎิทินฤกษ์มงคล 2560 ( ดูภาพประกอบ ) . . . NOTE :

  • หากติดที่ประตูรั้วไม่สะดวก ให้ราดน้ำ 5 ขันแทน
  • อย่านำวิธีการสำนักอื่นมาปนรวมกัน จะวัดผลไม่ได้
  • วิธีการวัดองศาให้แม่นยำ ... https://goo.gl/XDuFrM
  • คนที่แก้ไขก่อน 4 กพ. 2560 ค่อนข้างราบรื่น ไม่มีสะดุด
  • คนที่เจอปัญหา แล้วค่อยมาแก้ ปัญหาเบาบางลง
  • สอบถามจากศิษย์ที่เคยจัดบ้านให้

... ที่หน้าบ้านเป็นทิศใต้ และมีน้ำพุหน้าบ้าน ... ผลกระทบ ไม่มี ( ไม่ใช่ทุกองศาทำได้ ) ... มีอยู่รายนึง บอกว่า เขากลับขายดีขึ้น ... เพราะคู่แข่งเขาสะดุด ( ไม่ทราบทิศหน้าบ้านคู่แข่ง )
