ได้รับเชิญไปวิเคราะห์บ้านอาชา Archa ของคุณ Hung

📅 วันที่: 2015-12-15 📂 หมวดหมู่: บ้าน (Home) · ดวงจีน (Destiny) 📈 ความนิยม: 0

💡 สรุปใจความสำคัญ: ได้รับเชิญไปวิเคราะห์บ้านอาชา Archa ของคุณ Hung บ้านเลขที่ 999 เจ้าบ้านเป็นผู้ออกแบบตกแต่งเอง รูปลักษณ์สวยงาม โอ่โถง Design หลายอย่างน่าสนใจ โดยส่วนตัว...

ได้รับเชิญไปวิเคราะห์บ้านอาชา Archa ของคุณ Hung บ้านเลขที่ 999 เจ้าบ้านเป็นผู้ออกแบบตกแต่งเอง รูปลักษณ์สวยงาม โอ่โถง Design หลายอย่างน่าสนใจ โดยส่วนตัว ประทับใจกับราวบันไดห่วงกลมมาก วันนั้น มัวแต่มองเพลิน ลืมถ่ายรูป ขอให้ชมภาพที่ forfur.com เคยเยี่ยมชมบ้านแทนครับ http://goo.gl/BoKMmk

ชัยภูมิ จากประตูตรงเข้ามาจะพบวงเวียนบ่อปลาคาร์พ ( กลางบ่อ มีที่นั่งสีเขียว นั่งกลางน้ำ Creative สุด ๆ ) มีน้ำพุจำนวน 10 หัว ... แนะนำให้ปิดไป 2 เหลือ 8 ( ยุค 8 ... หลัง 4 กพ. 2567 เป็นยุค 9 ... ค่อยเปิดเป็น 9 หัว ) ด้านหลังเป็น อาชาขนาดใหญ่ ด้วยความภูมิใจในแซ่เบ๊ หลังประตูใหญ่ มองตรงไปจะเป็นบันได อยู่กลางหลังบ้าน ต่อมา เจ้าบ้านได้ทำฉากมาบังตา ทำให้เกิดความเป็นสัดส่วน ... เปิดประตู มองทะลุออกหลังบ้าน ส่วนหนึ่งคือ รั่วไหล ... อีกประเด็นคือ ขาดประธานเด่นชัด ขาดบารมี ด้านนอกหลังอาคาร ตรงกลาง กำลังสร้างสระว่ายน้ำ ด้านข้างซ้ายขวา เป็นบ่อปลาอีก 2 บ่อ

หลังจากวัดองศาแล้ว ได้ปรับเปลี่ยนฮวงจุ้ยภายใน ทำให้บทบาทดวงดาวที่ตำแหน่งประตูใหญ่ มีโชคลาภที่ดีขึ้น บ่อวงเวียนปลาคาร์พ ก็เป็นส่วนกระตุ้นโชคลาภด้วย ตำแหน่งดาวบารมีอยู่ด้านหลัง ซึ่งตรงกับฉากกั้น ( ไม่มีรูป ) ฉากกั้น มีงานสถาปัตย์ หัวม้าโลหะ เป็นประธานเด่น เสียดายที่ด้านหลังฉากเป็นแนวบันได และสระว่ายน้ำ ประธานเด่น แต่เคลื่อนไหว บารมีไม่มั่นคง จึงให้เสริมด้วยกระถางปูนเปลือยขนาดใหญ่ วางเรียงอยู่ด้านหลังอาคาร ช่วยค้ำไว้ ตำแหน่งเตาไฟ ค่อนข้างลงตัว ปรับเสริมเพียงเล็กน้อย

ตำแหน่งห้องพระ องศาดีลงตัว และเป็นราศีที่เสริมบารมีเจ้าบ้านให้โดดเด่น เพียงแต่องค์พระซ้ายขวา วางใต้แนวกรอบไม้หนา เสมือนหนึ่งเป็นคาน ... จึงหาฤกษ์ให้ขยับเดินหน้า และให้กราบไหว้เป็นประจำ

ตำแหน่งห้องนอน สวยงามลงตัว ทิศหัวเตียงกับดวงชะตาทั้งสามีภรรยา ก็ลงตัวดี ปรับย้ายนาฬิกาที่เดิมอยู่ในตำแหน่งลาภวิบัติ ให้ไปอยู่ตำแหน่งกระตุ้นโชคลาภแทน ( แก้ทีเดียวได้ 2 ต่อ จุดเสียหมดไป จุดดียิ่งดีขึ้น )

จากนั้น ปรับรายละเอียดในแต่ละห้องต่าง ๆ มีห้องน้ำเล็กห้องหนึ่ง หัวโถส้วมเกือบตรงแนวประตู ให้ปิดประตูห้องน้ำเป็นประจำ อย่าเปิดอ้าค้างไว้

นับเป็นหนึ่งในคฤหาสน์ที่ประทับใจ เป็นการวิเคราะห์ฮวงจุ้ยที่เพลินไปกับ ความคิดสร้างสรรค์เต็มเปี่ยมอยู่ทั่วบ้าน

Fengshui Balance ให้คำปรึกษาด้านฮวงจุ้ยอย่างครบถ้วนถูกต้อง และเป็นระบบ สอดคล้องกับแบบสถาปัตย์ และการใช้งานจริง ( ลองศึกษา Post ผลงานที่ผ่านมาดูก่อนครับ ) ปรึกษาได้จนจบงาน ( Turnkey Project ) ติดต่อ : Line http://line.me/ti/p/twX0_SxVSX

จัดปรับพื้นที่และสถาปัตยกรรมตามหลักฮวงจุ้ย

ให้คำปรึกษาและวิเคราะห์พื้นที่จริงสำหรับบ้าน คฤหาสน์ ออฟฟิศ และวางตำแหน่งศาลเจ้าที่/ตี่จู้ โดยอาจารย์สุภชัย วิวัฒนะประเสริฐ
