ประสบการณ์พิเศษ ( อีกครั้ง )

📅 วันที่: 2016-08-12 📂 หมวดหมู่: ศาลและตี่จู้ (Spirit House) · ออฟฟิศ (Office) 📈 ความนิยม: 0

💡 สรุปใจความสำคัญ: ประสบการณ์พิเศษ ( อีกครั้ง ) เมื่อวานบ่าย ไปกำหนดตำแหน่งตั้งศาลพระภูมิ ศาลตายาย ให้โรงงานใหม่ของ SNAIL WHITE ที่นิคมโรจนะ ... หลังจากเดินรอบโรงงาน มีพื้นที่ด้านหลัง...

ประสบการณ์พิเศษ ( อีกครั้ง ) เมื่อวานบ่าย ไปกำหนดตำแหน่งตั้งศาลพระภูมิ ศาลตายาย ให้โรงงานใหม่ของ SNAIL WHITE ที่นิคมโรจนะ ... หลังจากเดินรอบโรงงาน มีพื้นที่ด้านหลัง มีตำแหน่งและองศาที่ดีพอใช้ และมีมุมด้านหน้าโรงงาน ที่น่าจะเหมาะ

ระหว่างเดินไปจะถึงมุมด้านหน้าโรงงาน หัวหน้าคนงาน และลูกน้อง ชี้ให้ดูว่า มีต้นไม้ 3 - 4 ต้น ตรงกลางเป็นต้นไม้ใหญ่ จะเห็นพวงมาลัย ผ้าแพรรัดโคนต้นไม้ มีหลายคนเหมือนกันว่า ... มีหญิงไทย หน้าตาดี นุ่งชุดไทย ( แต่ไม่ใช่ชุดโบราณ ) เดินอยู่แถวนั้น ตอนเย็น ๆ และค่ำ ๆ อืมม์ ... มีแรงจูงใจ

หลังจากสำรวจพื้นที่ และวัดองศาแล้ว สรุปจบที่ตรงนี้ ตั้งห่างออกจากต้นไม้ ลงตัวทุกด้าน

  • ในแง่ฮวงจุ้ย

องศาดี ด้านหน้ามีโชคลาภทั้งยุค 8 และ 9 ลงตำแหน่งถนนด้านนอก และประตูด้านใน ดึงกระแสโชคลาภเข้าสู้พื้นที่ และกระตุ้นลาภได้ดี เวลาตั้ง ต้องระวังไม่ให้ตรง เสาไฟฟ้า

อีกประเด็น จะได้ถือโอกาสเชิญเจ้าที่ขึ้นเรือนศาล

  • ในแง่ชัยภูมิ และการใช้สอย

ตำแหน่งสวยสง่า ร่มรื่น ไม่ขัดต่อการขยายพื้นที่ในอนาคต ใกล้โถงพักทานข้าวพนักงาน จะได้สะดวกในการไหว้ เนื่องจากด้านหน้าศาลเป็นตำแหน่งโชคลาภ และตรงกับถนนใหญ่ ถือว่ากระแสลาภดีอยู่แล้ว แต่หากเพิ่มน้ำพุ จะทำให้บรรยากาศบริเวณนี้ ดูร่มรื่น หากขอบบ่อ ทำเป็นแท่นไว้นั่งรอบได้ พนักงานจะได้ใช้เป็นที่พักผ่อนหย่อนใจได้ด้วย

ทีมสถาปัตย์ จะเพิ่มพุ่มไม้ บริเวณบ่อน้ำพุ จึงแจ้งว่า อย่าบังด้านหน้าศาล ให้ปลูกด้านข้างแทน ยิ่งมีกลิ่นหอม หรือดอกสีสวย ๆ น่าจะทำให้ภูมิทัศน์สวยงาม น่านั่งพักผ่อน

หลังจากนั้น ไปกำหนดรายละเอียดจุดอื่น ๆ ตอนเย็น เมื่อเดินกลับมาเก็บเครื่องมือคนเดียว ลมพัดแรง ต้นไม้ใหญ่ต้นนั้นเหมือนสั่นไหว เสียงใบไม้ดังชัดเจน ( ไม่ได้คิดอะไร ) จู่ ๆ ก็รู้สึก ขนลุก ( แต่ไม่ได้ตกใจกลัว )

สังเกตุเห็นต้นไม้ด้านข้างซ้ายขวา ที่เหลือ ใบไม้กลับสั่นไหวน้อยมาก แทบไม่มีเสียงออกมา คิดว่า ท่านคงมาทักทาย ... จึงยกมือไหว้ บอกท่านว่า จะมาตั้งศาลให้ ... ลมค่อย ๆ สงบลง เดินกลับออกมา

โทรหาพราหมณ์ที่ทำงานด้วยกัน พราหมณ์บอกว่า ท่านเจ้าที่มาขอบใจที่จะตั้งศาลให้ นับเป็นอีกประสบการณ์พิเศษที่น่าจดจำ
