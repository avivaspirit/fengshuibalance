  • ร่างกายไม่สมดุล

... นอนไม่พอ หลับไม่ลึก ... ไม่ออกกำลังกาย ... ดื่มกิน สิ่งไม่มีประโยชน์ เหล้า บุหรี่ ... ( กาแฟ เกินวัน 3 แก้ว / ทานของหวานเกิน ) .

  • จิตไม่สมดุล

... ความเครียดจากงาน ... ความเครียดส่วนตัว ( เงิน / ครอบครัว ) ... ( ฝึกสติ สมาธิ ช่วยได้ดีมาก ) . . ในเชิงฮวงจุ้ย ( ขอกล่าวเฉพาะ ดวงชะตาก่อน ) ... ดวงชะตาเสียสมดุล ... โดยเฉพาะ ธาตุน้ำอ่อนแอ 🥹 ... ( ธาตุน้ำ - ไต กระเพาะปัสสาวะ มดลูก ) . โดยปกติ สามารถเสริมได้ด้วยการ ... นั่งพิง หรือหันหัวนอนไปทาง ทิศเหนือ ธาตุน้ำ ... หรือ ทิศตะวันตก ธาตุทอง -> ส่งเสริมน้ำ 💝 ... ( รายละเอียดฮวงจุ้ยอีกมาก เช่น ประตู ไม่ดี ก็ไม่มีลูก ) ... บางกรณี เหรียญปรับแก้ดวงก็ได้ผลดี 🤩 . . เบื้องต้น แนะนำ 💟
