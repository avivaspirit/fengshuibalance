ประตูตรงกัน 3 บาน และวิธีการแก้ไข

มีคนถามมา เห็นว่าน่าสนใจดี เลยเอามาเล่าสู่กันฟัง

จากรูป ตรงลูกศรแดง จะเป็นประตูหน้า และจะตรงประตูใน และประตูระเบียง ลักษณะเช่นนี้ เป็นประตูตรงกัน 3 บานจริง ( หากไม่ตรง ไม่นับ )

มองความเป็นจริง ( หยาง ) เมื่อมีลมมา ลมจะหาทางออกอย่างรวดเร็ว ประตูตรงกันเป็นเส้นตรง ลมพุ่งออกตรง ๆ มีความเร็ว วัสดุน้ำหนักเบา จะปลิวตามได้ง่าย เช่น กระดาษ แก้วพลาสติค ... หากลมแรง ของหนักก็ปลิวได้ ออกนอกบ้านไป

ด้านฮวงจุ้ย ( อิน ) ลมวิ่งเป็นเส้นตรง ไหลอย่างรวดเร็ว ... ชี่แรงเกิน หมายถึง สูญเสีย เสียหาย รั่วไหล อากาศไม่ไหลเวียนทั่วบ้าน บางจุดกลับจะเหม็นอับ ทำให้สุขภาพไม่ดี

ข้อสังเกตุ

  • ประตูต้องออกหลังบ้าน

หากตรงกันภายใน แต่ไม่ออกหลังบ้าน ไม่มีรั่วไหล ( แต่ด้อยเรื่องอากาศไหลเวียนไม่ทั่วถึง )

  • ไม่จำเป็นต้อง 3 บาน แค่ 2 บานและตรงออกหลังบ้าน

ก็ไม่ดีแล้วครับ จะพบบ่อยในบ้านเดี่ยวที่ต้องการ Show หลังบ้าน

  • ยิ่งตรงกันหลายบาน ลมยิ่งแรง

การแก้ไข

  • เปิดประตู ไม่พร้อมกัน ก็จบปัญหา
  • หรือหาสิ่งมาขวาง เช่น ตู้โชว์ ( ทึบ หรือมีกระจกบังลม )
  • เก้าอี้ Sofa ขนาดใหญ่ แก้ได้นิดหน่อย
  • บางท่านเป็นบ้านพักตากอากาศ ไม่ได้อยู่ประจำ

ความผูกพันระหว่างคนกับสถานที่มีน้อย ผลกระทบก็น้อยตาม

จัดปรับพื้นที่และสถาปัตยกรรมตามหลักฮวงจุ้ย

ให้คำปรึกษาและวิเคราะห์พื้นที่จริงสำหรับบ้าน คฤหาสน์ ออฟฟิศ และวางตำแหน่งศาลเจ้าที่/ตี่จู้ โดยอาจารย์สุภชัย วิวัฒนะประเสริฐ
