ทำไมเมื่อเปิดประตู จึงไม่ควรเห็น โต๊ะทานอาหาร ?

จาก Post เรื่อง Condo https://goo.gl/nY5NL2 สิ่งที่เราเห็น คือ มัณฑนากร ฟังปัญหา และวิเคราะห์ การใช้ชีวิตของแต่ละท่าน ... แล้วจึงหาทางแก้ไข ( เปรียบเสมือนเราเป็นหมอ รู้จักโรค แล้วจึงจัดยา )

ปัญหาหลัก ๆ คือ ความแออัด ( ส่วนใช้งานร่วมกัน / ห้องน้ำ ) และกิจกรรมต่าง ๆ ที่รบกวนระหว่างกัน ( กลิ่นอาหารจากครัว / เสียง + แสงไฟ รบกวนคนนอน )

สิ่งที่ทีมงานเขาปรับแก้

  • แยกครัวออก + ป้องกันกลิ่น และควัน
  • ห้องนอน แยกตามลำดับเวลานอนก่อนหลัง
  • โต๊ะทานข้าว แก้ปัญหาสุขภาพข้อเข่าผู้ใหญ๋
  • ห้องน้ำ ที่ใช้พร้อมกันได้ถึง 3 คน ( เหนือความคาดหมาย )

ในแง่มุมฮวงจุ้ย ท่านอ.เกรียงไกร มักจะใช้คำว่า "รู้จักแยกแยะ" ***

เรื่องภายใน เช่น การรับประทานอาหาร ถือเป็นเรื่องส่วนตัวในครอบครัว เราคงไม่ต้องการให้บุคคลภายนอกมาเห็นว่า ... เราทานอะไร มากน้อยขนาดไหน หรือแต่งตัวอย่างไร ... ห้องสะอาด หรือรก หรือเต็มไปด้วยยา Vitamin ฯลฯ

ดังนั้น เปิดประตูบ้านมาจึงควรเจอห้องรับแขกก่อน ( กรุณาอ่าน Post เดิม - ความสำคัญห้องรับแขก ) และไม่ควรเห็นโต๊ะทานข้าว หรือมีฉากบังตา ทำให้เกิดความเรียบร้อย แขกอยู่เป็นสัดส่วน

นี้คือ "รู้จักแยกแยะ" เรื่องภายนอก ภายใน รวมถึงเรื่อง "แยกแยะ" ว่าควรทำ หรือไม่ควรทำ ในชีวิตประจำวัน จะได้ใช้เวลาอย่างมีค่า

Note 1 : ธนวัฒน์ สุขัคคานนท์ หรือคุณตุ้ม แห่ง Interior Visions เป็นมัณฑนากรชื่อดัง เคยได้ร่วมงานกันในการออกแบบ บ้านให้ผู้ใหญ่ 2 ครั้ง คุณตุ้ม สามารถประยุกต์พลิกแพลง ตามเงื่อนไขฮวงจุ้ยได้อย่างรวดเร็ว สวยงามลงตัว และแน่นอน ค่าปรึกษาย่อมตามความสามารถ

Note 2 : ภาพสุดท้าย คือ ส่วนประทับใจในความคิดสร้างสรรค์ ลากเตียงออกมาเล็กน้อย กลายเป็น Sofa ได้ ( นับถือ )

ขอเชิญสมาชิกแสดงความเห็นพิ่มเติม หากมีประเด็นที่ดี น่าสนใจ ขออนุญาตนำมา Update ให้บทความสมบูรณ์ขึ้น ขอบคุณครับ

จัดปรับพื้นที่และสถาปัตยกรรมตามหลักฮวงจุ้ย

ให้คำปรึกษาและวิเคราะห์พื้นที่จริงสำหรับบ้าน คฤหาสน์ ออฟฟิศ และวางตำแหน่งศาลเจ้าที่/ตี่จู้ โดยอาจารย์สุภชัย วิวัฒนะประเสริฐ
