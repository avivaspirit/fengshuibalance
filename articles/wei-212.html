衡 Fengshui Balance ฮวงจุ้ย สมดุลแห่งธรรมชาติ
ปรึกษา วิธีทำงาน เคสงาน ผลงานอ้างอิง ประวัติ คลังความรู้ ติดต่ออาจารย์

ฮวงจุ้ยออฟฟิศและสำนักงาน (Office Fengshui)

ที่ปรึกษาฮวงจุ้ย: ปัจจัย 8 ข้อที่ทำให้วิเคราะห์ดวง ไม่ตรงตามจริง

📅 วันที่: 2016-08-16 📂 หมวดหมู่: ฮวงจุ้ยออฟฟิศ 📈 ความนิยม (WEI): 2,810
ปัจจัย 8 ข้อที่ทำให้วิเคราะห์ดวง ไม่ตรงตามจริง --------------------------------------- 1. วดป เวลาเกิด ไม่ถูกต้องตรงความเป็นจริง ... ใช้ วดป ตามบัตรประชาชน วิเคราะห์ไม่ได้ ... เพราะไม่ใช่เนื้อแท้ของดวงชะตา . 2. ทำดีมาก ๆ โดยเฉพาะ ลูกกตัญญู .... https://goo.gl/P4BDTI ... กรรมดีที่มีกุศลมาก จะช่วยทำให้เคราะห์เบาบางลง ... เปลี่ยนจากหนักเป็นเบา . 3. ทำเลวมาก ๆ โดยเฉพาะ ลูกอกตัญญู / ทำแท้ง ... ตรงกันข้ามกับข้อ 2 ... จังหวะดวงจะดี กลับไม่ได้ดีตามดวง ... เพราะกรรมหนักบดบังไว้ พลาดโอกาสที่ดีไป . 4. กรรมตัดรอน * ... กรรมใดที่ทำหน้าที่ฆ่ากรรมอื่นให้สิ้นสุดลงอย่างเด็ดขาด ... มีทั้ง กรรมฝ่ายดี และ กรรมฝ่ายชั่ว ... ในที่นี้ จะพูดถึงกรรมฝ่ายชั่ว ... ดวงแข็งแรงตามปกติ อยู่ ๆ กลับเสียชีวิตไม่ทราบเหตุ ... แพทย์ไม่สามารถวิเคราะห์ ระบุสาเหตุได้ . 5. พวกร่างทรงจริง ... มีพลังวิญญาณแทรก ขึ้น ๆ ลง ๆ ... ชีวิตจริงไม่เป็นไปตามพื้นดวงชะตาจริง ... มักไม่สามารถอ่านดวงตนเองได้ ... รวมทั้งไม่สามารถแก้ดวงให้ตนเองดีขึ้นได้ . 6. มีลางสังหรณ์ หรือมีสมาธิจิตสูง ... ผู้ฝึกสมาธิ มักรู้เหตุล่วงหน้า ... บ้างก็มี เทวดาผู้คุ้มครอง หรืออาจารย์มาแจ้งเตือน ... แต่บางคน Sense ไว รู้สึกไม่อยากออกจากบ้าน ... ถ้าออกนอกบ้านไป อาจเกิดเหตุ . 7. ฮวงจุ้ยดี และเหมาะกับดวงชะตา ... หากทิศหลังบ้าน หรือทิศหัวนอน ส่งเสริมดวง ... โดยเฉพาะกรณีเป็น "ธาตุสำคัญ" จะส่งผลมากเป็นพิเศษ ... เช่น ในดวงไม่มีราศีโชคลาภ แต่ได้ราศีทิศหัวนอนเป็นลาภ ... เท่ากับปิดจุดด้อยของดวง เมื่อเข้าอยู่ ชีวิตย่อมดีขึ้นชัดเจน ... และหากเป็นทิศทางองศาที่มีพลัง ... จะได้ผลเร็ว ได้ผลมาก ... เช่น หัวนอนมีบารมี ปลายเท้ามีโชคลาภ ... หรือ เป็นดวงบารมีอ่อน ลาภมาก ( เสียสมดุล ) ... ดวงอ่อนแอเกินไป รับลาภไม่ได้ ... แทนที่จะรวย กลับดีพอใช้ ... แต่พอได้นั่งโต๊ะทำงาน ที่ราศีส่งเสริมดวงชะตา ... ดวงแข็งแรงมากพอ รับลาภใหญ่ได้ ก้าวหน้ารวดเร็ว ... สุสานบรรพชน ก็มีผลมากเช่นกัน . 8. ฮวงจุ้ยไม่ดี ... ภาพรวม คือ ตรงข้ามกับข้างต้น ... เพิ่มเติม คือ เดิมอาจเคยอยู่ดี มีสุข ... แต่มีการต่อเติมออกไป เปลี่ยนย้ายประตู เพิ่มห้องน้ำ ... สิ่งที่สร้างใหม่อาจผิดตำแหน่ง ดังเช่น ... ที่เคยยกตัวอย่าง ชั้น 1 ต่อเติมพื้นที่โรงรถ ... จนห้องน้ำกลายไปอยู่ตรงกลางหลังบ้าน ... https://goo.gl/DTw705 ... หรือเปลี่ยนทิศหัวนอน แล้วไม่สบาย ... รวมไปถึง ฤกษ์ผิด เกิดเหตุรุนแรง ... สุสานบรรพชนแตกร้าว ทิศทางไม่ดี ... ลูกหลานรับผลกระทบเช่นเดียวกัน . .... PS : ต้นฉบับมี 6 ข้อ เป็นของท่านอ.เกรียงไกร ผมเพิ่มข้อ 4. กรรมตัดรอน และแยกฮวงจุ้ยดีและไม่ดีออกจากัน .... ใครมีประสบการณ์ในแต่ละข้อ เชิญเล่าสู่กันฟังครับ ไม่มีผิดถูกครับ ถือว่าแลกเปลี่ยนประสบการณ์

จัดปรับพื้นที่และสถาปัตยกรรมตามหลักฮวงจุ้ย

ให้คำปรึกษาและวิเคราะห์พื้นที่จริงสำหรับบ้าน คฤหาสน์ ออฟฟิศ และวางตำแหน่งศาลเจ้าที่/ตี่จู้ โดยอาจารย์สุภชัย วิวัฒนะประเสริฐ
