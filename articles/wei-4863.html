💡 สรุปใจความสำคัญ: เฉลยการบ้าน บันไดตรงประตูบ้าน ........................ 1. ทรัพย์รั่วไหล ( หากบันไดเยื้องไปด้านข้าง ไม่เป็นไร ) 2. เก็บความลับไม่อยู่ ( โจรมองเห็นทางหนีทีไล่ ) 3. บารมีไม่ดี -...

เฉลยการบ้าน บันไดตรงประตูบ้าน

  • ทรัพย์รั่วไหล ( หากบันไดเยื้องไปด้านข้าง ไม่เป็นไร )
  • เก็บความลับไม่อยู่ ( โจรมองเห็นทางหนีทีไล่ )
  • บารมีไม่ดี - หากตำแหน่งงาน หรือสุขภาพไม่ดี ยิ่งแย่
  • อยู่บ้านไม่ค่อยติด ( เป็นได้ทั้งสามี หรือภรรยาได้ )

คนจีน จะออกแบบ ด่านแรกเป็นห้องรับแขก ใครเข้าออก ผู้ใหญ่รับรู้ และจะมีการถามทุกข์สุขกัน ก่อเกิดความสัมพันธ์ กลมเลียว ช่วยเหลือกัน แน่นแฟ้น กลายเป็นครอบครัวใหญ่

ชาวตะวันตก เน้นความสะดวก เข้าออกขึ้นบนลงล่างได้ง่าย เข้าออก ไม่มีคนรับรู้ ต่างคนต่างอยู่ ความเป็นส่วนตัวสูง ตัวใครตัวมัน ความสัมพันธ์ห่างเหิน แยกออกไปเป็นครอบครัวเล็ก
