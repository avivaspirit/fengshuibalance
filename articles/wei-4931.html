ปรึกษา วิธีทำงาน เคสงาน ผลงานอ้างอิง สายวิชา คลังความรู้ ติดต่ออาจารย์

ฤกษ์มงคลและฤกษ์กระทำการ (Auspicious Timing)

ได้มีโอกาสจัดฮวงจุ้ยให้กับโรงแรม LM ที่พม่า

📅 วันที่: 2016-07-29 📂 หมวดหมู่: ฤกษ์มงคลและฤกษ์กระทำการ (Auspicious Timing) · บ้าน (Home) 📈 ความนิยม: 0

💡 สรุปใจความสำคัญ: ได้มีโอกาสจัดฮวงจุ้ยให้กับโรงแรม LM ที่พม่า จากปกติ ที่ใช้ฮวงจุ้ยกำหนดก่อน เช่น Layout ภาพรวม ตำแหน่งประตู Counter ฯลฯ แต่เนื่องจาก ... โรงแรมมีการก่อสร้างล่วงหน้าไปก่อนแล้ว...

ได้มีโอกาสจัดฮวงจุ้ยให้กับโรงแรม LM ที่พม่า จากปกติ ที่ใช้ฮวงจุ้ยกำหนดก่อน เช่น Layout ภาพรวม ตำแหน่งประตู Counter ฯลฯ แต่เนื่องจาก ... โรงแรมมีการก่อสร้างล่วงหน้าไปก่อนแล้ว ดังนั้น ต้องปรับฮวงจุ้ยให้เข้ากับสถานที่แทน

ภาพรวมภายนอก เป็นแนว Modern ทันสมัย สวยเรียบ อยู่แปลงหัวมุม จึงออกแบบให้สวยทั้ง 2 ด้าน ( จะอธิบายในแต่ละภาพอีกครั้ง ) ด้านข้างสร้างบรรยากาศด้วยน้ำพุ และน้ำตก เป็นส่วนภัตตาคาร รับลูกค้าภายนอกได้ด้วย

หลังจากเดินสำรวจชัยภูมิโดยรอบ และวัดองศาแล้ว ได้องศาที่ดี ด้านหลังมีบารมี ด้านมีโชคลาภทั้งยุค 8 และยุค 9

ปรับย้ายน้ำพุ ส่วนด้าน Main ของโรงแรม จากตำแหน่งเดิม ที่เป็นจุดเสียลาภ ย้ายมาด้านหน้า กลายเป็นจุดได้ลาภ

*** ตำแหน่งเหล่านี้ สำคัญมาก ***

วางผิด จะเสียหายมาก วางถูก โชคลาภดียาวต่อเนื่อง ดังนั้น เพื่อความปลอดภัย ไม่รู้จริง ไม่ตั้งจะดีกว่า แต่หากวัดองศาได้ละเอียดถูกต้อง เข้าใจบทบาทดวงดาวอย่างแท้จริง ตั้งได้ถูกต้อง กระตุ้นลาภได้ดี คุ้มค่าที่จะทำ

บ้านอาจไม่ค่อยจำเป็นเท่าไรนัก แต่ธุรกิจ หากทำได้ ควรทำ ... นอกจากกระตุ้นลาภได้ดี ยังช่วยสร้างบรรยากาศ และเป็นเสน่ห์ของสถานที่ ลองดู Post เดิม ของบริษัทฯ ที่ไต้หวัน สระน้ำพุ ขนาดใหญ่มาก

Lobby ขนาดปานกลาง ( จริงแล้ว Lobby ควรสูงและใหญ่กว่านี้ จะกำลังดี ) Counter สวยเด่นพอประมาณ แต่ Sofa รับแขกกลับเด่นกว่า จึงให้ปลดรูปวิวลง ปรับสี Sofa ให้กลมกลืน เพื่อให้ Counter ซึ่งเป็นประธานพื้นที่ เด่นสุด

Design ด้านในมีความสวย Modern มาก ตั้งแต่ทางเดิน ห้องพัก ห้องน้ำแบบ See Through ยังแซวท่านเจ้าของว่า Modern ไปไหม :) มีการปรับแก้รายละเอียดในห้องเล็กน้อย

จากนั้นไปจัดฮวงจุ้ยภัตตาคาร จัดยากเล็กน้อย เพราะตำแหน่งประตูเข้าออกมีหลายจุด เลือกปิดจุดที่ไม่สำคัญ และกำหนดตำแหน่งเตาไฟ Counter เก็บเงิน ฯลฯ ตรงนี้ ก็มีน้ำพุเช่นกัน แต่จากภาพน้ำพุขึ้นสูงมาก ( ลาภต้องอยู่ที่ต่ำ ลาภสูงเกิน ลาภล้น กลับจะเสียลาภ ) เลยให้ปรับให้ต่ำลง และให้จำนวนหัวสอดคล้องกับดาว

จุดสุดท้าย คือ ตำแหน่งตั้งศาล ไปตั้งอยู่ในส่วนลานจอดรถ หันมาที่หน้าประตูโรงแรมเป็นถนนทางยาวมาก ถนนทางยิ่งยาว กระแสพุ่งชนยิ่งแรง ( หยางมาก ) ตั้งรับด้วยศาล ขนาดใหญ่เหมาะสม ( อินมาก ) เมื่อได้องศาที่ดี ด้านหลังเป็นบารมี ด้านหน้าโชคลาภ หยางแรง อินรับได้ ... กระแสเข้าหากัน ศาลจะมีพลัง ศักดิ์สิทธิ์มาก ดึงโชคลาภเข้าอาคารได้ดี กำหนดจุดตั้งไว้เรียบร้อย เมื่อโรงแรมใกล้เสร็จ จึงค่อยตั้งอย่างเต็มพิธี

Fengshui Balance ให้คำปรึกษาด้านฮวงจุ้ย ( ชัยภูมิ ทิศทาง ดวงจีน ฤกษ์ ) อย่างครบถ้วนถูกต้อง และเป็นระบบ สอดคล้องกับแบบสถาปัตย์ และการใช้งานจริง ( อลงศึกษา Post ผลงานที่ผ่านมาดูก่อนครับ ) ปรึกษาได้จนจบงาน ( Turnkey Project ) ติดต่อ : inbox Line ID : suppachaibig Line PC : http://line.me/ti/p/twX0_SxVSX
