FanPage ท่านนี้ เธอติดตามและศึกษา Page มานาน จนมั่นใจในวิธีการปรับแก้ฮวงจุ้ยของเรา บังเอิญเพื่อนรุ่นพี่สามีเธอ ก็ได้แนะนำเราให้เธอเช่นกัน

จัดฮวงจุ้ย Office ที่ PB Tower สุขุมวิท 71 องศาที่ได้ค่อนข้างดี แต่เนื่องจากเป็นองศาขอบพลังทีดี ที่กำลังเข้าสู่องศาที่ไม่ดี จึงต้องวัดอีก 3 มุม เพื่อยันกัน ปรากฎว่า อยู่ในช่วงองศาที่ดีหมดทั้ง 4 มุม สบายใจได้

กำหนดตำแหน่งประตู ป้าย Logo บริษัทฯ เนื่องจากเป็นทิศทางที่ดี ตำแหน่งประตูเป็นดาวโชคลาภ ให้ตั้ง Counter และ Logo ให้ตรงแนวประตูตรง ๆ รับโชคลาภได้เต็มที่

จากนั้น วิเคราะห์ดวงชะตาผู้บริหาร กำหนดตำแหน่งห้อง และทิศทางการนั่ง ให้สอดคล้องกับหลักฮวงจุ้ย ( อิน ) และการใช้งานจริง ( หยาง ) ด้องดูดี มีสง่าราศี

ซินแสบางท่านยึดเรื่องดวง โดยไม่สนใจความเหมาะสม เช่น ให้นั่งหันหลังให้ประตูห้อง เวลาใครเข้าห้องมา ... บางครั้งเจ้าของก็ไม่รู้ตัว ( เสียเปรียบ ) หากรู้ตัว ก็ต้องหมุนตัวมามอง ( ขาดความสง่า ) แม้แต่มองผ่านเข้ามาในห้อง ก็แลดูไม่งาม ขาดบารมี

จัดพื้นที่ตามหลักฮวงจุ้ย และการใช้สอยจริง เช่น หัวหน้า นั่งอยู่ด้านหลัง / หรือด้านใน โต๊ะที่ดีเป็นพิเศษ จะให้คนสำคัญนั่ง ฯลฯ .. หลังจากสรุปแบบแล้ว ให้ทาง interior ส่งแบบ Final มาให้ Proof ก่อน แล้วจึงหาฤกษ์ให้ดำเนินการ ยุ่งยากเล็กน้อย ตอนกำหนดตำแหน่ง Air บางจุด คือ ลงตำแหน่งที่ดีที่สุดไม่ได้ ต้องไปลงดีอันดับ 2 แทน

เนื่องจากเจ้าของกำลังตั้งครรภ์ แนะนำให้สามี เป็นผู้มาตรวจงานแทน แต่ถ้าจะมาตรวจเอง แนะให้ช่างหยุดงานก่อน แล้วค่อยเดินตรวจ ป้องการการกระทบกับเด็กในครรภ์ ( เคยเขียนถึงไปแล้ว )
