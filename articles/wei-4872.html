อาคารตามภาพ ( ผัง - สีเขียว ) พิงองศาที่ดี ดาวโชคลาภประจำยุคอยู่ที่หน้าประตู Office และ มีโชคลาภหนุนอยู่หน้าประตูรั้ว ( ผัง - สามเหลี่ยม ) ถือว่าดีมาก ๆ ( ดีต่อเนื่อง 29 ปีนับจากนี้ ) ..... แต่ในความเป็นจริง ยอดขายกลับไม่ได้ตามเป้า มีค่าใช้จ่ายเยอะผิดปกติ พนง.บางคนไร้ประสิทธิภาพ

สาเหตุเพราะ

  • สร้างบ่อปลา ( ผัง - สีฟ้า ) เพื่อกระตุ้นโชคลาภ

แต่เนื่องจากวางผิดตำแหน่ง ลงดาวลาภวิบัติ ทำให้มีค่าใช้จ่ายสูง ลาภผลรั่วไหล

  • ตั้งศาล ( ผัง - สีเหลือง ) หันหน้าเข้าหาอาาคาร

คือ หันสวนกัน ... ลูกน้องมักมีปัญหา และตำแหน่งตั้งศาล ขวางดาวลาภหนุน ได้ลาภน้อยลง

  • ห้องบางแผนก ประตูลงดาวไม่ดี

ผลงานแผนกนั้น ทุกคนต่ำกว่าเกณฑ์ พนง.บางคนเมื่อย้ายไปอยู่ห้องอื่น ผลงานกลับดีขึ้น

  • ตำแหน่งตั้งพระ มีมากไปเล็กน้อย

บางตำแหน่ง ตั้งแล้วกลับไม่ดี

การแก้ไข โดยหลักการของเราจะเน้นประหยัด ไม่่มีการรื้อทุบ ให้ปรับเปลี่ยนโดยเกิด คชจ.น้อยสุด ( รื้อทุบ คชจ.มากขึ้นแน่นอน โดยไม่มีรายได้มารองรับ ) โดยให้แก้เบื้องต้น หากทุกอย่างดีขึ้นจริง ค่อยทำใหญ่

การแก้ไขเบื้องต้น

  • สูบน้ำ ย้ายปลาออก ( ยังไม่ต้องทุบ )

ปิดด้วยผ้าใบ ไม่ให้น้ำฝนลงไปขัง

  • ปรับเปลี่ยนทิศทางแผนกที่มีปัญหา
  • ย้ายตำแหน่งพระบางจุดที่มีปัญหา ไปรวมกับทิศที่ดี

สิ่งที่เกิดขึ้นแบบวัดผลได้

  • การรั่วไหลน้อยลง
  • ยอดขายดีขึ้น มียอดใหญ่
  • ผลงานของแผนกนั้น ดีขึ้น

การแก้ไขขั้นตอนสุดท้าย ( รอฤกษ์ ) ถมบ่อ แล้วย้ายศาลมา หันหน้าทิศทางเดียวกับอาคาร ( ไม่ใช่กฎตายตัว ) เป็นการแก้ตำแหน่งลาภวิบัติอาคาร ( เรื่องที่รั่วไหลเล็ก ๆ น้อย ๆ ก็จะน้อยลงไปอีก ) และเท่ากับแก้ปัญหา ศาล หันสวนทางกับ Office หลัก ทำให้บารมีเจ้าของดีขึ้น ลูกน้องเชื่อฟัง

Fengshui Balance ให้คำปรึกษาด้านฮวงจุ้ยอย่างครบถ้วนถูกต้อง และเป็นระบบ ปรึกษาได้จนจบงาน ( Turnkey Project )

จัดปรับพื้นที่และสถาปัตยกรรมตามหลักฮวงจุ้ย

ให้คำปรึกษาและวิเคราะห์พื้นที่จริงสำหรับบ้าน คฤหาสน์ ออฟฟิศ และวางตำแหน่งศาลเจ้าที่/ตี่จู้ โดยอาจารย์สุภชัย วิวัฒนะประเสริฐ
