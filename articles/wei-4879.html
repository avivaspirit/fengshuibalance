💡 สรุปใจความสำคัญ: STEP 2/3 : หลังจากปรับแก้ฮวงจุ้ยขั้นแรก โรงงานที่จ.ตาก ได้ผลดีแบบวัดผลได้ชัดเจน เจ้าของพอใจในผลลัพธ์ที่ได้ ... การปรับแก้คร่าว ๆ ( รายละเอียดกรุณาอ่าน Post เดิม ) 1....

STEP 2/3 : หลังจากปรับแก้ฮวงจุ้ยขั้นแรก โรงงานที่จ.ตาก ได้ผลดีแบบวัดผลได้ชัดเจน เจ้าของพอใจในผลลัพธ์ที่ได้ ... การปรับแก้คร่าว ๆ ( รายละเอียดกรุณาอ่าน Post เดิม )

  • ปรับย้ายตำแหน่งเจ้าที่ ( ตี่จู้เอี้ย )
  • ปรับแก้ดวงชะตาผู้บริหาร
  • ปรับตำแหน่งที่นั่ง ห้องทำงาน
  • ย้ายประตูห้องทำงานด้านนอก

จริง ๆ แล้ว ข้อ 4. ต้องเป็นแผนที่ 2 เพราะมีค่าใช้จ่ายสูง แต่บังเอิญช่างกำลังแก้หน้างาน เจ้าของเลยให้ทำต่อไปด้วยเลย สะดวกกว่าไปตามมาใหม่ ... ผลที่ได้

  • ปัญหาบุคลากรลดลง ลูกน้องเชื่อฟังมากขึ้น ( บารมีดีขึ้น )
  • Output ผลผลิตต่อหัว เพิ่มมากขึ้น ... การประสานงานดีขึ้น

จำนวนลูกน้องลดลง แต่ผลผลิตดีขึ้น ( ลดค่าใช้จ่าย )

  • ลูกค้ารายเดิมที่เคยหายไป หลายรายติดต่อกลับมาเอง

ท่านเจ้าของโรงงาน เลยขอให้ปรับแก้ฮวงจุ้ย แผน 2 ต่อ คือ ย้ายตำแหน่งศาลพระภูมิ ศาลตายาย ... ของเดิม ( ภาพ 1 ) ผิดพลาด 4 ประการ

  • ตั้งศาลหันหน้าเข้าหาโรงงาน ความหมาย คือ สั่งอย่างได้อย่าง
  • ด้านหลังศาลเป็นถนน ( บารมีขาดความมั่นคง )
  • ตำแหน่งที่ตั้งศาล เป็นตำแหน่งทำให้โชคลาภลดลง
  • องศาของศาลดี แต่ตั้งไม่เหมาะสมกับสภาพแวดล้อม

โดยเฉพาะตำแหน่งน้ำพุหลัก หน้า Office จึงได้ย้ายศาลไปตำแหน่งใหม่ ใกล้ประตูทางเข้าโรงงาน เป็นองศารุ่งเรืองในยุค 8 ( หน้าโชคลาภ หลังบารมี ) หน้าศาลรับกับกระแสโชคลาภที่มาจากถนนตรงเข้าสู่ประตูรั้ว ตั้งในฤกษ์เปิดทรัพย์ 4 ทิศที่ผ่านมา ( ตุลาคม 2558 )

ผลลัพธ์ บุคลากรระดับหัวหน้า มีความร่วมมือในการทำงานดีขึ้นมาก ช่วยกันปรับปรุงแก้ไข ทำให้ลดอัตราการสูญเสียได้มาก Output ดีขึ้นกว่าเดิมมาก จนสามารถลดชม. OT ลงได้ ประหยัดค่าใช้จ่าย ... แต่คนงานแอบบ่น ( ฮา )

จนกระทั่ง เจ้าของเริ่มเครียด ... เนื่องจาก Output ที่ดีขึ้นอย่างรวดเร็ว ทำให้ Order ที่มีอยู่ จะหมดลงในอีก 1 เดือนข้างหน้า ได้โทรหาลูกค้าเก่า ๆ ทุกราย ก็ได้ Order ขึ้นมาบ้าง แต่ไม่มากพอ สำหรับการวางแผนผลิตในระยะยาว

โทรมาปรึกษา ... ได้แนะนำไปว่า ให้ไปจัดของไหว้ จุดธูป ไหว้ของานที่ศาลพระภูมิ ศาลตายาย ด้วยว่า เป็นองศารุ่งเรือง มีพลัง ประกอบกับฤกษ์ที่ตั้งก็ดีมาก เชื่อว่า จะได้ผลดีรวดเร็ว

หลังจากที่ได้ทำตามที่แนะนำแล้ว ท่านเจ้าของก็พยายาม วิ่งหางาน ... ในที่สุด ก็ได้รับสาย แจ้งข่าวดี ได้ Big Order ทำให้พนักงานมีงานทำได้อีกหลายเดือน

โปรดสังเกตุว่า ฮวงจุ้ยจะได้ผลดี ได้ผลเร็ว ได้ผลมาก ต้องเกิดจาก อิน+หยาง ประสานกัน อิน คือ การปรับแก้ไขฮวงจุ้ย + หยาง คือ การปฎิบัติงานตามหน้าที่ ด้วยความขยัน รับผิดชอบ
