... ก็ห้าม "เริ่มต้น" ที่ทิศนี้ .

  • หากจะมีการซ่อมแซมปรับปรุงบ้าน

... ( เดือนนี้ ได้เฉพาะหลังบ้าน S และ E ) ... ให้เอาค้อนยางกระทบที่ ตรงกลางหลังบ้าน ... ( ไม่จำเป็นต้องให้แตกหัก ) 🤩 ... เดินวนซ้ายหรือขวา เคาะไปรอบบ้าน 1 รอบ ... หลังจากนั้น ซ่อมแซมบ้านได้ .

  • หากเป็นการเปลี่ยนย้ายจุดสำคัญ

... A โต๊ะทำงาน ... B เตียงนอน ... C สิ่งศักดิ์สิทธิ์ ... ห้ามยุ่งเกี่ยวกับทิศ N และ W 📌

  • จุดแรกที่จะเริ่มต้นกระทบ

... ต้องราดน้ำ 5 ขันก่อน 💧 ... โดยเฉพาะเดือนนี้ ทิศใต้มีดาวเบญจภูติอยู่

ฤกษ์นี้ ไม่เหมาะติดแผ่นกั้ว 🎯 เพราะต้องดูฤกษ์ทั้งทิศหลังบ้านและหน้าบ้าน ให้ไปใช้ฤกษ์เดือนเมษ 14 หรือ 26 / 4 / 65 .... 21.30-22.30 16 หรือ 28 / 4 / 65 .... 17.30-18.30
