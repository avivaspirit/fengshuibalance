ฤกษ์มงคลและฤกษ์กระทำการ (Auspicious Timing)

อ. สุภชัย: บันไดทางขึ้นลง ตรงแนวประตูตรง ๆ

📅 วันที่: 2016-11-24 📂 หมวดหมู่: 🏠 บ้าน · 📅 ฤกษ์ยาม 📈 ความนิยม: 2,835
บันไดทางขึ้นลง ตรงแนวประตูตรง ๆ ความหมายคือ รั่วไหล ( หนัก ) ( ถ้าไม่ตรงประตู ไม่เป็นไร ) . เมื่อวัดองศาแล้ว ทิศทางอาคารหลังนี้ดีมาก ด้านหลังมีบารมี ประตูเป็นดาวโชคลาภ แต่เมื่อเจอลักษณะดังกล่าว สิ่งที่ดี ๆ กลับรั่วไหลหมด . ข้อเท็จจริง อาคารที่อยู่ติดกันทั้งหมด ก่อสร้างในลักษณะเดียวกัน ทั้งหมดมีสภาพที่ไม่สวยงามเท่าใดนัก . การปรับแก้ไข มีหลายวิธี แล้วแต่องศา และการใช้งานจริง 1. ย้ายประตู 2. ย้ายบันได 3. หักมุมทางลง 4. แบ่งกั้นห้อง บังบันไดให้เรียบร้อย . สำหรับอาคารหลังนี้ เจ้าบ้านเลือกข้อ 3 + 4 เพราะต้องการให้ห้องโถงกว้างใหญ่ . ....... เนื้อหาดี มีประโยชน์ โปรดช่วย Share ... อ่านสาระฮวงจุ้ยอย่างมีแนวคิด ✔ กด Like เพจ ✔ กดติดตาม เลือก "See First / เห็นก่อน" ( นโยบายใหม่ Facebook ท่านจะเห็นเราน้อยมาก ) ( ยกเว้น กดเลือก See First ) ------------------------- Fengshui Balance ให้คำปรึกษาด้านฮวงจุ้ย ( ชัยภูมิ ทิศทาง ดวงจีน ฤกษ์ ) อย่างครบถ้วนถูกต้อง และเป็นระบบ สอดคล้องกับแบบสถาปัตย์ และการใช้งานจริง ( ลองศึกษา Post ผลงานที่ผ่านมาดูก่อนครับ ) ปรึกษาได้จนจบงาน ( Turnkey Project ) ติดต่อ : inbox
