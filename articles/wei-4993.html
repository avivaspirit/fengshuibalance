ตั้งเจ้าที่ ... เล็งแนวเสาให้ดี !!

ภาค 3 ของบ้านหลังเดิม

ภาพซ้าย ตี่จู้ตั้งพิงกำแพง ปกติ เรียบร้อยดี แต่เมื่อมองตรงไปด้านหน้า กลับพบว่า ด้านหน้าตี่จู้ ตรงกับเสา ( ที่แขวนนาฬิกา ) สังเกตได้จากแนวกระเบื้อง

นับเป็นการสร้างบ้านที่แปลก เพราะเสาอาคารเยื้องเหลื่อมกัน ( ปกติ ต้องตรงเป็นแนวเดียวกัน )

ในแง่ฮวงจุ้ย เสาและแนวกำแพงกีดขวาง ทำสิ่งใดก็ติดขัด ผิดหวัง

การแก้ไข ย้ายตี่จู้หลบแนวเสา แต่เนื่องจากกำแพงนี้ ไม่มีที่เหลือ จึงต้องหลบไปวางพิงกำแพงอื่น ( ต้องดูฤกษ์ และตำแหน่งดวงดาวประกอบ )

สังเกตภาพที่ 2 ทางซ้ายเป็นประตูหน้าบ้าน + กระจกใส คือที่มาคำถามภาค 1 : https://goo.gl/cKcBjI
