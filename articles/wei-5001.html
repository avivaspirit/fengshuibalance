ไปจัดฮวงจุ้ยของ FanPage ที่ The Plant Exclusique เป็นหลังที่ 3 แล้ว

เป็นบ้านเดียวขนาดกลาง ชัยภูมิภายนอก มีเพียงช่องลมระหว่าง บ้านฝั่งตรงข้าม 2 หลัง แต่ผลกระทบน้อย เพราะช่องลมใหญ่ ( ช่องลมที่น่ากลัว คือ แคบเล็กจากตึกสูง ) รวมถึงมีต้นไม้บังไว้ และมีถนนคั่นกลาง

เสาไฟอยู่ฝั่งตรงข้าม ไม่ตรงหน้าประตูบ้าน ไม่ตรงประตูรั้ว ไม่มีผลกระทบใด ๆ

วัดองศาอย่างละเอียดได้ 358 องศา เป็นทิศเกือบเหนือตรง เป็นบทบาทที่ดีประจำยุค 8 "โชคลาภเกื้อหนุนบารมี" กล่าวคือ ได้ลาภก่อน ได้บารมีภายหลัง ประตูบ้านเป็นตำแหน่งดาวโชคลาภ ยุค 8 เหนือประตูจึงให้ติด Air กระตุ้นลาภให้มากขึ้น

ช่องลมทางชัยภูมิ ที่ได้กล่างถึงไป ความหมายคือ กระแสมีกำลัง เมื่อเป็นตำแหน่งดาวลาภ กลับจะได้ลาภมากขึ้น ดังที่เคยได้อธิบายไปใน Case ที่ Singapore https://goo.gl/jJ3zPT

เดิมเจ้าบ้านจะติด Air 2 จุด คือหน้าและหลังบ้าน แต่ได้ห้ามไว้ เพราะ

  • ปกติ ตรงกลางหลังบ้าน เป็นบารมีทางชัยภูมิ
  • หลังบ้านเป็นตำแหน่งบารมีหนุน ต้องนิ่ง มั่นคง

ดังนั้น หากติด Air หลังบ้าน ... บารมีจะด้อย หน้าที่การงานไม่เด่น สุขภาพไม่แข็งแรง ( คำตอบข้อ 2 เฉพาะองศาบ้านหลังนี้เท่านั้น )

สรุป ติด Air ตัวใหญ่ที่หน้าประตูอย่างเดียวพอ และด้านหลังบ้านจะตั้งเจ้าที่แทน เลยเสนอให้ทาสีกำแพงหลังบ้านใหม่ เช่น Pastel สีเขียวอ่อน หรือฟ้าอ่อน เพื่อให้เกิดความโดดเด่น โดยเฉพาะเมื่อวางเจ้าที่

แปลงนี้ จะจัดง่ายกว่าแปลงใหญ่ก่อนหน้า เพราะไม่มีเสากลางบ้าน https://goo.gl/ivlJr2

หลังจากนั้น วิเคราะห์ดวงชะตา กับสิ่งที่เกิดขึ้นจริง ขั้นตอนนี้ หากวิเคราะห์ดวงไม่ถูกต้อง จะไม่สามารถกำหนดตำแหน่งทิศหัวนอนได้ถูกต้อง แต่บ่อยครั้ง ที่ทิศหัวนอนของสามีภรรยาจัดยาก เพราะบางทีราศีธาตุที่ดวงต้องการต่างกัน ก็ต้องพยายามหาทิศที่ไม่ติดลบกับใคร แต่บางครั้ง อาจต้องเน้น

  • ปรับแก้สุขภาพเป็นอันดับแรก

... ( หากมีเงิน แต่ป่วย ก็เอาเงินไปรักษาอีก )

  • อาจต้องเน้นช่วยเสาหลักของบ้าน

ทั้งหมดนี้ ไม่มีการรือทุบแก้ใด ๆ เจ้าบ้านต้องการปูกระเบื้องรอบนอกบ้าน แต่ได้ขอให้เหลือสนามหญ้าไว้บ้าง เพราะบรรยากาศความร่มรื่นจะหมดไป สีเขียวต้นไม้ มีส่วนช่วยให้เราลดความเครียด ปลูกไว้มีแต่เรื่องดี เพียงแต่ห้ามรกครึ้มเกินไป

จัดฮวงจุ้ยแท้จริง เน้นวิชาการ ( ทิศทาง ดวง ดาว ... ) ไม่มีการใช้กระจก สิงห์ ยันต์ ( เพราะต้นฉบับวิชาก็ไม่มี )

จัดบ้านให้สวยเรียบง่าย ระวังจุดที่กำหนดไว้ เพียงเท่านี้ อยู่แล้วมีความเจริญรุ่งเรืองได้ดี .

Fengshui Balance ให้คำปรึกษาด้านฮวงจุ้ย ( ชัยภูมิ ทิศทาง ดวงจีน ฤกษ์ ) อย่างครบถ้วนถูกต้อง และเป็นระบบ สอดคล้องกับแบบสถาปัตย์ และการใช้งานจริง ( ลองศึกษา Post ผลงานที่ผ่านมาดูก่อนครับ ) ปรึกษาได้จนจบงาน ( Turnkey Project ) ติดต่อ : Line http://line.me/ti/p/twX0_SxVSX
