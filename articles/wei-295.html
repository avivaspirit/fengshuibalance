ดูฮวงจุ้ยออฟฟิศ: มีสิ่งใดผิดปกติ ?

📅 วันที่: 2016-12-17 📂 หมวดหมู่: ฮวงจุ้ยออฟฟิศ 📈 ความนิยม (WEI): 2,299
มีสิ่งใดผิดปกติ ? 【 เฉลย 】 อาคารได้มีการออกแบบทางสถาปัตย์ก่อนวางฮวงจุ้ย เดิมบันไดหลักไปหลบอยู่ด้านใน ขาดความโดดเด่น หลังการปรับฮวงจุ้ย ได้ย้ายห้องรับรองแขกมาอยู่ด้านหน้า แง่ฮวงจุ้ย 1. ประตูห้องเป็นตำแหน่งโชคลาภ 2. ประตูรั้วเป็นตำแหน่งโชคลาภด้วยเช่นกัน แง่ใช้สอย 1. ห้องรับแขกอยู่ด้านนอก โอ่โถงกว่า ... ( อาคารยังตกแต่งไม่แล้วเสร็จ ) 2. สะดวกกับแขกในการเดินเข้าสู่อาคาร 3. แยกเป็นสัดส่วน ระหว่างแขกกับ Office ด้านใน . เดิม คิดว่าท่านเจ้าของคงทุบบันไดเก่าทิ้ง แต่งานยุ่งมาก ลืมแจ้งผู้รับเหมาไป กลายเป็น 2 บันได ทำให้เกิดความสับสน ( ใครตอบประเด็นนี้ถูก เอาไป ✔ 1 คะแนน ) . ท่านจึงวางแผนจะวางกระถางต้นไม้ ลงบนขั้นบันได ให้สวยงามแทน นับเป็นการแก้ไขที่ดี ต้องเก็บไว้แนะนำท่านอื่น :) . บันไดเล็ก ไม่เหมาะสมกับตัวอาคารที่ใหญ่โต ( ✔ คะแนนที่ 2 ) ควรขยายบันไดที่ตรงกับประตูให้ใหญ่ขึ้นจนสุดช่วงเสา ( ✔ คะแนนที่ 3 ) เป็นคำตอบตรงใจข้าพเจ้ามากสุด ยกนิ้วให้ @Wirach Udomote . บันไดเล็ก ไม่มีราวข้างให้จับ ไม่ปลอดภัย ตอบถูกหลายท่าน ( ✔ คะแนนที่ 4 ) . ตอบ Comment ดังต่อไปนี้ 1. มุมอาคารพุงชนประตูรั้วทางเข้า ... ถ้าเป็นเช่นนั้นจริง ทุกตึกใหญ่ บ้านเดี่ยว ก็เป็นหมด ... มุมแหลม 45 มีผลด้านความรู้สึก ... ( ดังนั้น คนที่จิตเข้มแข็ง จะไม่รู้สึกใด ๆ เลย ) ... และมุมแหลม 45 ไม่มีผลด้านฮวงจุ้ย *** แนวขอบกำแพง หรือสันอาคาร มีผลมากกว่ามาก *** *** ให้ลองนึกถึง เวลาลมพัดแรง ๆ ยืนตรงไหน ลมแรงสุด *** นั้นคือ สิ่งที่เกิดขึ้นจริง ( ไว้จะทำภาพประกอบให้ครับ ) . 2. เสาไม่ได้ขวางประตู เพราะประตูตรงบันได . 3. ท่อระบายน้ำ ... เป็นจุดผมไม่ทันได้สังเกตุ ... FanPage ยอดเยี่ยมจริงครับ ( ✔ คะแนนที่ 5 ) ... ท่านเจ้าของจัดท่อไปลงทางอื่นแล้วครับ . Note แนงทางเบื้องต้น ในการทำให้ประตูเด่นกว่าเดิม ผนังกระจกใส อาจติด Film กันแดด หรือ Film ขุ่น หรือ วางกระถางต้นไม้เรียงรายไปรอบ ๆ เพื่อให้ประตูอาคารชัดเจนขึ้น . . ขอบคุณ ท่านเจ้าของอาคาร ที่เอื้อเฟื้อ อนุญาตให้นำภาพมาเพื่อการศึกษา ถือเป็น "ครู" ในการศึกษา ดังนั้น ต้องวิเคราะห์ วิจารณ์ด้วยความสุภาพ ให้เกียรติแก่เจ้าของภาพ บ่งบอกว่า "ธาตุไฟ - มารยาท" ของท่าน มีบทบาทที่ดี จึงจะเป็นคุณสมบัติผู้เรียนรู้ที่ดี . ....... เนื้อหาดี มีประโยชน์ โปรดช่วย Share ... อ่านสาระฮวงจุ้ยอย่างมีแนวคิด ✔ กด Like เพจ ✔ กดติดตาม เลือก "See First / เห็นก่อน" ( นโยบายใหม่ Facebook ท่านจะเห็นเราน้อยมาก ) ( ยกเว้น กดเลือก See First ) ------------------------- Fengshui Balance ให้คำปรึกษาด้านฮวงจุ้ย ( ชัยภูมิ ทิศทาง ดวงจีน ฤกษ์ ) อย่างครบถ้วนถูกต้อง และเป็นระบบ สอดคล้องกับแบบสถาปัตย์ และการใช้งานจริง ( ลองศึกษา Post ผลงานที่ผ่านมาดูก่อนครับ ) ปรึกษาได้จนจบงาน ( Turnkey Project ) ติดต่อ : inbox Line ID : suppachaibig Line PC : http://line.me/ti/p/twX0_SxVSX
