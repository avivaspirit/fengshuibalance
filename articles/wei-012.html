อังคาร 5 มค. 2564 .... 19.30 - 20.45 น. 🚩 . ( หากไม่อยู่ในช่วงเวลานี้ ก็คือ ไม่ใช่ฤกษ์ ) . A. ให้ทำบุญก่อน โดยการโอนเงินไปทำบุญ ... เช่น บริจาคให้โรงพยาบาล . ... สำหรับ ท่านที่ไม่ได้ทำมานาน แนะนำทำสัก 3 แห่ง ... กรวดน้ำด้วย อุทิศให้เจ้ากรรมนายเวร ด้วยจิตเมตตา ... และให้พ่อแม่ ครูอาจารย์ ท่านเจ้าที่ เทวดาผู้คุ้มครอง . B. 19.30 ... สวดมนต์ ไหว้พระ 💥 ... ถวายส้ม 3 ใบ + น้ำ ... ( + พวงมาลัยมะลิ หรือดาวเรือง ได้ยิ่งดี ) ... ไม่ต้องจุดธูป ให้ไหว้อย่างตั้งใจ ... 1 ชุด ไหว้ร่วมกันได้ทุกคน . ... ให้นึกถึงบุญกุศลที่ได้ทำมา ... ( อาจเปิดดูภาพในมือถือ ) ... ยิ่งเกิดปิติ ขนลุกยิ่งดี ... แผ่บุญให้กับเจ้ากรรมนายเวรด้วยจิตที่เมตตา . C. 19.45 นั่งสมาธิ ( ในห้องที่สงบ ) ... นั่งพิง SW … หันหน้าไป NE ( ออกเฉียงเหนือ ) *** ... ( ใช้เข็มทิศในมือถือช่วย ) ... นั่งอย่างน้อย 30 นาที . 20.15 นั่งอยู่ที่เดิม 🔺 แล้วให้ขอพร ตามข้างต้น ( ในขอบเขตที่เป็นไปได้เท่านั้น ) 🎉
