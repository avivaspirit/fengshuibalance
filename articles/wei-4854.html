ไปดูบ้านให้ลูกค้า ... โครงการเดิมที่เพิ่งไปมา The Palm

📅 วันที่: 2015-04-17 📂 หมวดหมู่: บ้าน (Home) · ดวงจีน (Destiny) 📈 ความนิยม: 0

💡 สรุปใจความสำคัญ: ไปดูบ้านให้ลูกค้า ... โครงการเดิมที่เพิ่งไปมา The Palm คราวนี้ ดูบ้าน 2 หลัง หันหลังชนกัน ... องศาเกือบหมดสภาพ ( คงบ้วง ) หลังแรก จัดไม่ยุ่งยากเท่าไรนัก ... หลังที่ 2 ......

ไปดูบ้านให้ลูกค้า ... โครงการเดิมที่เพิ่งไปมา The Palm คราวนี้ ดูบ้าน 2 หลัง หันหลังชนกัน ... องศาเกือบหมดสภาพ ( คงบ้วง ) หลังแรก จัดไม่ยุ่งยากเท่าไรนัก

หลังที่ 2 ... จัดยากกว่ามาก เพราะประตูเป็นตำแหน่งดาว 25 ลาภวิบัติ ( และบทบาทดาวคือ แม่หม้าย ) ต้องปรับทิศทางกันใหม่ เพื่อให้ได้บทบาทโชคลาภ และลงตัวในการใช้สอย ( ข้อหลังสำคัญ )

ห้องนอน ย้ายหัวเตียงนอน เพราะธาตุทิศเดิมให้โทษกับดวงชะตา รวมถึง บทบาทประตูก็ลงตัวเสียหายเช่นกัน แต่ย้ายใหม่ ธาตุทิศเป็นโชคลาภของดวง ... ประตูลงบทบาทดาวที่ดี และแก้ปัญหา ประตูห้องน้ำตรงเตียง ไปด้วย ( เจ้าบ้านกลัวตรงนี้มาก )

ตอนแรก เจ้าบ้านกลัวว่าต้องแก้เยอะ ต้องรื้อทุบ ใช้งานไม่สะดวก ต้องวางของแก้มากมาย วางหิน วางสิงห์ แบบที่เคยเจอ หมดทีหลายหมื่น แล้วไม่ได้ผลอะไร รู้สึกเหมือนถูกหลอก ( เพื่อน ๆ โดนทั้ง Gang )

สรุปแก้ไขหลักไม่กี่จุด นอกนั้น เป็นพวกจุดเสริมลาภ บารมี ( Option )

ภาพประกอบ เป็นตัวอย่างห้องนอน ที่ติดกระจกส่องเตียง ความหมาย คือ ไม่จริง หลอก ทางปฎิบัติ หากเป็นคนจิตอ่อน อาจตกใจกลัว กรณีตื่นยามดึก จึงไม่ควรมีกระจกส่องเตียง

จัดปรับพื้นที่และสถาปัตยกรรมตามหลักฮวงจุ้ย

ให้คำปรึกษาและวิเคราะห์พื้นที่จริงสำหรับบ้าน คฤหาสน์ ออฟฟิศ และวางตำแหน่งศาลเจ้าที่/ตี่จู้ โดยอาจารย์สุภชัย วิวัฒนะประเสริฐ
