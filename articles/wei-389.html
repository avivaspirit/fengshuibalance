Fengshui Balance ฮวงจุ้ย สมดุลแห่งธรรมชาติ
ปรึกษา วิธีทำงาน เคสงาน ผลงานอ้างอิง ประวัติ คลังความรู้ ติดต่ออาจารย์

ฮวงจุ้ยออฟฟิศและสำนักงาน (Office Fengshui)

ที่ปรึกษาฮวงจุ้ย: เฉลยประเด็น ปี่เซียะคู่นี้ หันหน้าไปที่ประตูใหญ่

📅 วันที่: 2016-05-11 📂 หมวดหมู่: 🏢 ออฟฟิศ · 🏠 บ้าน 📈 ความนิยม: 1,919
【 เฉลย】 ปี่เซียะคู่นี้ หันหน้าไปที่ประตูใหญ่ คำถาม วางถูก หรือผิดอย่างไร ? ( ตัดประเด็น ตัวผู้ตัวเมีย และกระจก 8 เหลี่ยมด้านล่าง ) ... 【 คำตอบ】 ปี่เซียะคู่นี้ "ไม่ได้เฝ้ามอง" ประตูใหญ่ แต่มองท้องฟ้า โดยปกติ เขาจะวางไว้ต่ำกว่านี้ และใกล้ประตูใหญ่ จะมองตำแหน่งประตูพอดี ... ยกสูง อยู่ห่าง กลายเป็นมองท้องฟ้า *** ไม่มีความจำเป็นใด ๆ ในการตั้ง *** ตั้งแล้ว ที่แน่ ๆ เสียเงิน ( ค่าสินค้า + ค่าวัสดุ + ค่าติดตั้ง + ค่าซินแส + ... ) ... สมัยก่อน บ้านขุนนางจีนนิยมตั้งสิงห์ เพื่อบ่งบอกถึงอำนาจ บารมี ให้คนเกรงขาม ปัจจุบัน ไม่แนะนำให้ตั้ง ตั้งแล้ว เพื่อนบ้านไม่สบายใจ ไม่ใช่เรื่องดี "อยู่ที่ไหน ต้องเป็นมิตรที่นั่น จึงจะดี" ... NOTE : ใช้เวลา 9 วัน กับการบอกใบ้ตลอด จึงจะมีคนตอบถูก ( กรุณาดูชื่อด้านล่าง ) ... เชิญมารับรางวัล Pyramid หินอ่อน ขนาดเล็ก 12 cm สำหรับฝึกสมาธิ ทำให้จิตนิ่งได้เร็วขึ้น ลดความเครียด ( มูลค่า 950 บาท ) ... จำนวน 1 รางวัล Note : ต้องมารับเองที่ Office พระราม 3 ( ส่งไปรษณีย์ แตกหักแน่นอน จึงต้องให้มารับเองครับ ) แผนที่ http://www.avivaspirit.com/map-address-avivaspirit/

จัดปรับพื้นที่และสถาปัตยกรรมตามหลักฮวงจุ้ย

ให้คำปรึกษาและวิเคราะห์พื้นที่จริงสำหรับบ้าน คฤหาสน์ ออฟฟิศ และวางตำแหน่งศาลเจ้าที่/ตี่จู้ โดยอาจารย์สุภชัย วิวัฒนะประเสริฐ
