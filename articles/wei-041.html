ห้องและโต๊ะเรียนหนังสือที่ดี ------------------------------- ตอนที่ 1 - จัดตามหลักความเป็นจริง ( หยาง ) https://www.facebook.com/FengshuiBalance/posts/pfbid02aQ59y3UD4o1BxgyZS4zTK743eCicqesTQaBnwweF4STFuF3cQn5aELvAzg7zj7Vhl ------------------------------- ตอนที่ 2 - จัดตามหลักฮวงจุ้ย ( อิน ) . การจัดต้องยืนพื้นจากหลักความเป็นจริงก่อนเสมอ 🎯 แล้วมา Optimize จัดให้เหมาะสมกับดวงชะตา และบทบาทของดวงดาว . ฮวงจุ้ย ประกอบไปด้วย 4 วิชาหลัก และวิเคราะห์ตามลำดับ ดังนี้ 1. ชัยภูมิ 🚩 ... ห้ามนั่งใต้คาน - แบกหนัก มึนหัว สมองไม่แล่น ... ห้ามนั่งตรงประตู - คนเข้าออก ดึงดูดสมาธิ ... ( ยกเว้น องศาที่ประตูดีมาก ) ... หันหลังให้ประตู ... หากเป็นห้องทำงานรับแขก ไม่ควร ... แต่เป็นห้องศึกษา อ่านหนังสือ ไม่เป็นไร ... กระจกเงา - จะดึงสมาธิไป . 2. ดวงชะตา 🚩 ... เราจะวิเคราะห์ดวงเพื่อปรับสมดุล ... พลังงาน ( ลี่ ) ในตัวให้สมดุล จิตแจ่มใส ... เรียนรู้ได้ดี เข้าใจได้รวดเร็ว ... กรณีที่ไม่สามารถนั่งทิศที่ดีได้ ... ก็เลือกทิศไม่ให้โทษ เช่น ทิศคู่แข่ง อุปสรรค ... รวมถึง ทิศที่ไม่ดีกับสุขภาพ ... ยกตัวอย่างแบบง่าย ๆ ( พื้นฐาน ) ... คนขี้ร้อน ควรนั่งพิงทิศเหนือ ( น้ำ ) จะสมดุล ... แต่ในรายละเอียด ต้องมาดูราศี หากชงก็ไม่ดี ... ถ้าได้ทิศนั่งปัญญา - ดี ( เก่ง ) ... ได้ทิศความสำเร็จ - ดีเลิศ ( เก่ง + เฮง ) หายากมาก . 3. ดวงดาว 🚩 ... ทำไมบางห้อง ไม่ว่าคนเก่งหรือไม่เก่งไปอยู่ ... ล้วนไม่ประสบความสำเร็จ ... อาจเพราะตำแหน่งประตูวิบัติ ... หรือ ตำแหน่ง Air เป้นลาภวิบัติ ... จึงมีแต่เรื่องสูญเสีย ไร้ผลงาน ... Layout เหมือนกัน องศาต่างกัน ตำตอบต่างกัน . ... เคล็ดลับปี 2567 - 4/2/2568 ✴️ ... ทิศ NW ของห้องนั้น ... ให้วางดินสอแหลม 4 แท่งในถ้วย ... เสริมเพิ่มให้มีพลังอีก ... วางถ้วยเหนือแผ่นกั้ว ดาว 4 - ปัญญา . . 4. ฤกษ์ยาม 🚩 ... ขยับย้ายจุดสำคัญ เช่น พระ โต๊ะทำงาน ... ต้องดูฤกษ์ ( สำคัญมาก ) ... ฤกษ์ดี ได้ผลเร็ว ได้ผลมาก . . *** ทั้งหมดข้างต้น เป็นเรื่อง"ฮวงจุ้ย" . . เคล็ดลับเสริม 💝 -------------- 1. ไปไหว้ บุ่นเชียงตี่กุน ( เทพปัญญา ) ... ที่วัดมังกรกมลาวาส (วัดเล่งเน่ยยี่) ถนนเจริญกรุง . 2. ถวายเครื่องเขียน ตำรา แก่พระภิกษุสงฆ์ . 3. การนอนหลับ พักผ่อน ให้เพียงพอ ... รวมถึง ออกกำลังกายอย่างเหมาะสม ... และสัมผัสธรรมชาติ Grounding ... ช่วยปรับสมดุลชีวิต มีสุขภาพจิตดี . 4. Mindset สำคัญมาก ... ทำให้ดีที่สุด ... ได้เท่าไร ก็เท่านั้น . 5. กำลังใจ ความเห็นใจจากพ่อแม่ ... คนรอบข้าง มีผลหมด . 6. ฝึกสมาธิ ประโยชน์สูงมาก . 7. พกแท่งพลังงานสมาธิ Wisdom ... ✳️ Focus ขยัน มุ่งมั่น มีสมาธิ ปัญญา https://www.facebook.com/Miracles369/posts/498042575436481 . 8. หากต้องการมาก Pyramid Wisdom & Success ... ได้ผลดีกว่า และส่งผลให้ทุกคนที่อยู่ในห้อง ... โดยเฉพาะ ผู้ที่ต้องปัญญามาก เช่น ป.โท . .
