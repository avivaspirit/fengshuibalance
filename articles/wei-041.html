ตอนที่ 2 - จัดตามหลักฮวงจุ้ย ( อิน ) . การจัดต้องยืนพื้นจากหลักความเป็นจริงก่อนเสมอ 🎯 แล้วมา Optimize จัดให้เหมาะสมกับดวงชะตา และบทบาทของดวงดาว . ฮวงจุ้ย ประกอบไปด้วย 4 วิชาหลัก และวิเคราะห์ตามลำดับ ดังนี้

  • ชัยภูมิ 🚩

... ห้ามนั่งใต้คาน - แบกหนัก มึนหัว สมองไม่แล่น ... ห้ามนั่งตรงประตู - คนเข้าออก ดึงดูดสมาธิ ... ( ยกเว้น องศาที่ประตูดีมาก ) ... หันหลังให้ประตู ... หากเป็นห้องทำงานรับแขก ไม่ควร ... แต่เป็นห้องศึกษา อ่านหนังสือ ไม่เป็นไร ... กระจกเงา - จะดึงสมาธิไป .

  • ดวงชะตา 🚩

... เราจะวิเคราะห์ดวงเพื่อปรับสมดุล ... พลังงาน ( ลี่ ) ในตัวให้สมดุล จิตแจ่มใส ... เรียนรู้ได้ดี เข้าใจได้รวดเร็ว ... กรณีที่ไม่สามารถนั่งทิศที่ดีได้ ... ก็เลือกทิศไม่ให้โทษ เช่น ทิศคู่แข่ง อุปสรรค ... รวมถึง ทิศที่ไม่ดีกับสุขภาพ ... ยกตัวอย่างแบบง่าย ๆ ( พื้นฐาน ) ... คนขี้ร้อน ควรนั่งพิงทิศเหนือ ( น้ำ ) จะสมดุล ... แต่ในรายละเอียด ต้องมาดูราศี หากชงก็ไม่ดี ... ถ้าได้ทิศนั่งปัญญา - ดี ( เก่ง ) ... ได้ทิศความสำเร็จ - ดีเลิศ ( เก่ง + เฮง ) หายากมาก .

  • ดวงดาว 🚩

... ทำไมบางห้อง ไม่ว่าคนเก่งหรือไม่เก่งไปอยู่ ... ล้วนไม่ประสบความสำเร็จ ... อาจเพราะตำแหน่งประตูวิบัติ ... หรือ ตำแหน่ง Air เป้นลาภวิบัติ ... จึงมีแต่เรื่องสูญเสีย ไร้ผลงาน ... Layout เหมือนกัน องศาต่างกัน ตำตอบต่างกัน . ... เคล็ดลับปี 2567 - 4/2/2568 ✴️ ... ทิศ NW ของห้องนั้น ... ให้วางดินสอแหลม 4 แท่งในถ้วย ... เสริมเพิ่มให้มีพลังอีก ... วางถ้วยเหนือแผ่นกั้ว ดาว 4 - ปัญญา . .

  • ฤกษ์ยาม 🚩

... ขยับย้ายจุดสำคัญ เช่น พระ โต๊ะทำงาน ... ต้องดูฤกษ์ ( สำคัญมาก ) ... ฤกษ์ดี ได้ผลเร็ว ได้ผลมาก . .
