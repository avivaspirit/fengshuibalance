เริ่มต้น "ปีมังกร" อย่างเป็นทางการ ตามหลักโหราศาสตร์วิชาการ ( สุริยคติ ) 🚩 ( ไม่ใช่ ตามจันทรคติ - ตรุษจีน ) . ราศีที่ชง คือ "ปีจอ" เท่านั้น 🎯 ที่เหลือเป็น เฮ้ง ผั่ว ไห่ ( ไม่มี ชง 75% 50% 25% ) อันนั้น "ชง Marketing" สร้างประเด็นขายของ . ท่านที่มี ราศีจอ ในดวง จะถูกกระทบ

  • ปิเกิด
  • เดือนเกิด ( 8 ตค - 7 พย. โดยประมาณ )
  • วันจอ ( ต้องผูกดวง - ดูด้านล่าง )
  • ยามจอ ( 19.00 - 20.59 น. )
