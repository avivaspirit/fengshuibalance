หมู่บ้านแห่งหนึ่งที่ภูเก็ต

📅 วันที่: 2022-12-19 📂 หมวดหมู่: 🏠 บ้าน · 📝 บันทึกฮวงจุ้ย 📈 ความนิยม: 276

หมู่บ้านแห่งหนึ่งที่ภูเก็ต ... ถนนสูงกว่าพื้นบ้าน ... ผลกระทบคือ . มองในแง่ข้อเท็จจริง 🎯

  • ฝนตก น้ำไหลเข้าบ้าน -> น้ำท่วม

... หากท่วมหนัก พื้นบ้าน เฟอร์นิเจอร์เสียหาย

  • ฝุ่น สิ่งสกปรก เข้าบ้าน
  • รถ เข้าออก ลำบาก

. ในแง่ฮวงจุ้ย ✴️ ถนน เปรียบเสมือนสายน้ำ หรือ โชคลาภ เมื่อสายน้ำอยู่สูงกว่าพื้นเรือน ก็คือ น้ำท่วมเรือน จะมีเรื่องรั่วไหล เสียทรัพย์ . การปรับแก้ไข 🚩

  • ถ้าต่ำกว่าเล็กน้อย อาจยกพื้นสูงขึ้น ( ดูฤกษ์ )
  • กรณีสูงกว่ามาก เช่นในภาพ

... จะยกแท่นหนุนเจ้าที่ให้เท่าหรือสูงกว่าถนน ... ( เจ้าที่ เปรียบได้กับ ประธานบ้าน ) ... ( ดูภาพประกอบ - และต้องดูฤกษ์ปรับแก้ )

  • Case นี้ ... โชคดีตรงที่ว่า

... ด้านขวาของภาพ มีอีกอาารเล็ก ( ขออภัย ลืมถ่าย ) ... ที่สร้างใหม่ และสูงกว่าถนน ... จึงกำหนดจุดสำคัญ อยู่ที่อาคารเล็กนี้แทน ... ดังนั้น ผลกระทบด้านลบ ลดลง . . ✅ ตอบคำถาม ตามหลักฮวงจุ้ยสร้างบ้านสูงกว่าถนนได้สูงสุดเท่าไร ? ... ตอบตามหลักวิศวกรรม ( ได้เคยคุยกับหลายท่าน ) ... ถ้าจะต้องมีการปรับใหม่ ... แนะนำว่า 50 cm เหมาะสมสุด ในแง่การใช้สอย ... ( ราคาก็เป็นเงื่อนไขสำคัญ ) ... สูงมาก ... เปลืองเงิน รถขึ้นยาก ใช้งานไม่สะดวก .

จัดปรับพื้นที่และสถาปัตยกรรมตามหลักฮวงจุ้ย

ให้คำปรึกษาและวิเคราะห์พื้นที่จริงสำหรับบ้าน คฤหาสน์ ออฟฟิศ และวางตำแหน่งศาลเจ้าที่/ตี่จู้ โดยอาจารย์สุภชัย วิวัฒนะประเสริฐ
