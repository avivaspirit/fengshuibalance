Fanpage เชิญให้ไปจัดฮวงจุ้ยบ้านให้ ( บ้านเดี่ยวราคาประมาณ 10 ล้านเศษ ) โครงการ The Plant Exclusique ของพฤกษา

หลังจากวัดองศาบ้านได้ 150.5 ต้องขอแสดงความยินดีกับเจ้าบ้านและภรรยา เพราะเป็นองศา "รุ่งเรือง" ในยุค 8 คือ ด้านหน้ามีดาวโชคลาภ ด้านหลังมีดาวบารมี ( ช่วงองศาที่ดี คือ 150 +/-4.5 หรือ 145.5 - 154.5 )

เมื่อมองไปรอบ ๆ จะพบข้อด้อยชัยภูมิภายใน

  • เสาเดี่ยวกลางโถงบ้าน

... ผลกระทบ คือ แบกภาระหนัก และโรคหัวใจ ... ( รายละเอียด https://goo.gl/ua29k4 )

  • กระจกใสบานใหญ่ ฝั่งตรงข้ามประตูบ้าน

ตำแหน่งบารมีทางชัยภูมิเสีย และดาวบารมีหมดสภาพ

การแก้ไข ทำฉากกั้นหน้าหลัง เชื่อมต่อระหว่างเสาเดี่ยวกับกำแพงด้านข้าง เท่ากับ แก้ทีเดียว 2 ปัญหา คือ ปัญหาเสาเดี่ยวกลางโถงหายไป และกำแพงใหม่บังกระจกหลังบ้าน ตำแหน่งบารมีโดดเด่น และมั่นคงขึ้น

และกำแพงใหม่นี้ ให้ตั้งตี่จู้หินอ่อนให้ตรงประตูบ้าน ( โดยธรรมเนียมคนจีน ถือเป็นการให้เกียรติ เคารพเจ้าที่ ) ( เหนือเจ้าที่ สามารถตั้งพระ หรือเทพได้ ) บารมีต้องนิ่ง มั่นคง ... ด้านหน้าโชคลาภ ต้องเคลื่อนไหว เมื่อตรงประตู เคลื่อนไหวมาก ลาภมากตาม

กำแพงที่เพิ่มใหม่นี้ ทึบเฉพาะส่วนที่ตั้งตี่จู้ก็เพียงพอ และสีให้เด่นกว่าส่วนอื่น ๆ เล็กน้อย เพื่อเป็นจุดเด่น ( ด้านข้าง โปร่งบางส่วนได้ เพื่อมิให้ดูแน่นจนเกินไป ) เท่ากับเราสามารถรับพลัง "รุ่งเรือง" ได้เต็มที่

หลังจากนั้น เป็นการจัดฮวงจุ้ยในจุดที่สำคัญต่าง ๆ ได้แก่ ห้องครัว ห้องพระ ห้องนอน โต๊ะทำงาน เน้นทิศทางให้ปรับดวงชะตาให้สมดุล เช่น ดวงป่วย ต้องทำให้หายป่วยก่อน สุขภาพต้องดี ดวงลาภอ่อน ก็ปรับเสริมลาภให้มีกำลังมากขึ้น ห้องนอน - จะเน้นเรื่องสุขภาพ ความสัมพันธ์ในครอบครัว โต๊ะทำงาน - จะเน้นเรื่องโชคลาภมากขึ้น

ทั้งหมดนี้ ไม่มีการรื้อโครงสร้างใด ๆ เลย มีแต่เจ้าบ้านต่อเติมดัดแปลงโรงรถเป็นห้องทำงาน ภรรยาต้องการบ่อเลี้ยงปลา ก็แนะนำตำแหน่งที่วางแล้วได้โชคลาภให้

หมายเหตุ บ้านด้านหลัง สร้างขนานกัน ดังนั้น องศาหลังบ้านจะเป็นตรงข้าม คือ 330 เป็นองศารุ่งเรืองเช่นกัน แต่จะเด่นยิ่งกว่า เพราะมีดาวโชคลาภในยุคถัดไปอยู่หน้าบ้าน ถ้าเจ้าบ้านยังไม่โอน คงได้ย้ายแปลงกันแล้ว :) ( ไม่แน่ใจว่า ยังมีแปลงว่างเหลืออีกไหม )

แล้วบ้านฝั่งตรงข้ามล่ะ น่าเสียดาย ถนนหน้าบ้านเอียง บ้านฝั่งตรงข้ามไม่ขนานกัน จึงไม่สามารถคาดเดาองศาได้

Fengshui Balance ให้คำปรึกษาด้านฮวงจุ้ย ( ชัยภูมิ ทิศทาง ดวงจีน ฤกษ์ ) อย่างครบถ้วนถูกต้อง และเป็นระบบ สอดคล้องกับแบบสถาปัตย์ และการใช้งานจริง ( ลองศึกษา Post ผลงานที่ผ่านมาดูก่อนครับ ) ปรึกษาได้จนจบงาน ( Turnkey Project ) ติดต่อ : Line http://line.me/ti/p/twX0_SxVSX
