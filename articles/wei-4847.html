งานบรรยายฮวงจุ้ยประจำปี 2558 ของชมรมภูมิโหราศาสตร์ โดยท่านอ.เกรียงไกร บุญธกานนท์ สรุปใจความ

  • ปีนี้ ระบบนับอิมเป็น "แพะทอง" คนกตัญญูจะได้ดี
  • เมืองไทย ระวังเหตุวุ่นวายหลังกลางปี
  • จีนโดดเด่น ... อเมริกาดูดีแต่ภายนอก
  • หลังบ้านทิศตะวันตก เป็นทิศห้ามประจำปี ( ห้ามทุบ รื้อ ซ่อม )
  • หน้าบ้านทิศตะวันตก ... การค้าสะดุด ติดขัด ค่อนข้างมาก

.... ( วิธีแก้ไข ศึกษาได้จากหน้า 89 หนังสือปฎิทินฤกษ์มงคล )

  • หน้าบ้านทิศใต้ ... ให้ระวัง ของเสีย ของหาย ขโมย
  • เปลี่ยนเป็นปีนักษัตรแพะ ( เริ่ม 4 กพ. 2558 - ระบบสุริยคติ

.... ใช้ในการวิเคราะห์ดวง ... ไม่ใช่ วันตรุษจีน - จันทรคติ ) .....คนที่ชง คือ ปีฉลู เท่านั้น ..... *** ไม่มี ชง 75 50 25 *** ลองดูซินแสเมืองจีนก็ไม่มี .... และที่สำคัญ คือ คนเกิดเดือนฉลู ( 6 มกรา - 4 กพ. ) ชงแรงที่สุด .... การแก้ไข รับมอบเหรียญปรับแก้ดวงชง กรุณาดูหน้า 99

  • ในงานบรรยาย แนะวิธีกระตุ้นทรัพย์ ในฤกษ์เปิดทรัพย์ 4 ทิศ

.... ให้กับบรรดาผู้ฟัง ( ไว้จะแนะนำอีกครั้ง เมื่อใกล้ถึงฤกษ์ )

  • หลังจากนั้น วิเคราะห์ภาพชัยภูมิเมืองจีน

..... และ 4 แยกสาทร-นราธิวาส อ่านความหมายและวิธีการ

  • นัดหมาย เชิญชวนไหว้ขอพรฟ้า ณ เทียนฐานเมืองไทย สระบุรี

..... เสาร์ 14 มีนาคม 2558 ( ร่วมงานฟรี - รายละเอียดในเล่ม )
