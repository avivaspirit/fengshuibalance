"ต่อเติม" ต้องระวัง ... จะบานปลาย

ภาพที่ 2 - ผังซ้ายมือ เป็นบ้านที่กำลังสร้าง และห้องน้ำอยู่ริม ( สีส้ม ) ต่อมา เจ้าบ้านเปลี่ยนใจเพิ่มพื้นที่ชั้นล่าง ตำแหน่งห้องน้ำ กลายเป็นตรงกลางหลังบ้าน ( ผังขวา )

กลางหลังบ้าน ความหมาย คือ ประธานบ้าน เป็นจุดเด่น เป็นตัวแทนเจ้าบ้าน ต้องนิ่ง มั่นคง หากเป็น ห้องน้ำ ( เคลื่อนไหว ) บารมีขาดความมั่นคง ชื่อเสียงไม่ดี การงานไม่ก้าวหน้า หากดวงตก ... สุขภาพมีปัญหามาก เป็นกรณีที่ซินแสทุกคนล้วนส่ายหัว

เป็น Case แรกในรอบหลายปีมานี้ ที่ต้องขอให้เจ้าบ้าน "ย้ายห้องน้ำ" กลางหลังบ้าน แม้วิธีผ่อนหนักเป็นเบา แต่ก็ยังไม่ดี อยู่ในระหว่างก่อสร้าง จึงไม่ยุ่งยากจนเกินไปนัก

นอกจากประเด็นนี้แล้ว การใช้สอยจริง ก็ไม่ค่อยสะดวกนัก ต้องผ่านห้องครัวก่อน ( แต่ละหลังไม่เหมือนกัน ) ย้ายไปตำแหน่งใหม่ ใช้งานสะดวกกว่า สวยกว่า
