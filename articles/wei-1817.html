ทั่วไป มักจะเรียก ที่ทำเสริมดวงชะตาว่า แซกี ... แต่ของ อ.เกรียงไกร จะเรียกตามนี้ .

  • เจ่าอุ่ง *

... ทำเพื่อตนเอง ... ใช้ขณะมีชีวิตอยู่ ( มักมีขนาดเล็ก ไม่ได้ฝัง ) ... ตายแล้ว ต้องยกเลิก .

  • ฮกกี

... ทำเพื่อตนเอง + ลูกหลาน ... คำนวณยากกว่า เพราะต้องดู คู่ครอง + ปีเกิดลูกหลาน ... มีขนาดใหญ่ ( สำหรับบรรจุร่างตนเอง + คู่ครอง ) .

  • แซกี

... ลูกหลาน ทำให้พ่อแม่ ... เพื่อให้ รุ่นลูกหลาน ได้ดี . . สุสาน ทำให้ลูกหลานรวมตัวกัน ( สามัคคี ) 🥰 มากราบไหว้ ระลึกพระคุณพ่อแม่ ( กตัญญู ) . อ.เกรียงไกร ท่านกล่าวว่า ... พ่อแม่ ดูแล พวกเราตลอดทั้งชีวิต ... แต่ละปี ... ขอ 1 วัน ให้ไปดูแล ระลึกถึงท่าน ... เปิดโอกาสให้ลูกหลาน ... ได้กระทำความดี แสดงความกตัญญูรู้คุณ ... เราดูแลพ่อแม่อย่างไร ... ลูกหลานเราก็จะปฎิบัติตามนั้น 💝
