【 เฉลย / สรุปสุดท้าย】 ขอบคุณในความไว้วางใจ จากผู้บริหารไทย - ญี่ปุ่น Siam Betsukawa Co., Ltd. ที่ให้ไปจัดฮวงจุ้ยให้เมื่อประมาณปีกว่า ๆ

ภาพแรก ... องศาของ Office ส่วนหน้าโรงงาน ถือว่าดี ( โปรดสังเกตุ ขนาดประตูใหญ่ ตามขนาดโรงงาน ) ( บรรยากาศดูสะอาดตา ทันสมัย โปร่งโล่ง ดูดี ) แต่ประตูรั้วใหญ่ บทบาทกลับธรรมดา ไม่เด่นเรื่องลาภ ... จึงต้องตั้งศาลเจ้าที่ช่วย จัดแท่นวางให้ได้องศาที่รุ่งเรือง ดึงกระแสโชคลาภ เข้าสู่พื้นที่ได้ สวยลงตัวกับการใช้สอย ผลคือ ... ธุรกิจมีความเจริญก้าวหน้า เติบโตได้ตามเป้า ผลประกอบการถือว่าดี โดยเฉพาะเศรษฐกิจนิ่ง ๆ แบบนี้ ผิดกับโรงงานรอบข้างหลายแห่งที่เริ่มมีปัญหา ลดคนงาน

จนกระทั่ง โรงงานด้านข้างมีปัญหา ที่สำคัญ โรงงานแห่งนี้ เชิญซินแสมาแก้แล้วหลายท่าน เฉพาะศาลพระภูมิขนาดใหญ่ มีการย้ายตำแหน่งหลายหน ยิ่งแก้ ยิ่งแย่ ปัญหามากมาย ... สุดท้าย ประกาศขาย

ทาง Siam Betsukawa จึงเข้าไปซื้อ เพื่อขยายกิจการ ( เป็นสิ่งบ่งบอก ธุรกิจก้าวหน้าจริง จนมีเงินไปซื้อที่ดินใหม่ ) และขอเชิญให้ไปจัดฮวงจุ้ยให้ใหม่อีกครั้ง

【 เฉลย】 ภาพ 2 - ถ่ายจากด้านใน Office ของโรงงานที่มีปัญหา

  • ประตูเตี้ยเกินไป + ติด Film เข้ม ทำให้ดูเล็กไป เมื่อเทียบกับตัวโรงงาน

( ดูภาพที่ 1 เปรียบเทียบบรรยากาศ ) ประตู คือ ปาก - สื่อระหว่างภายนอกและภายใน ( เป็นคำสอนของท่าน อ.เกรียงไกร บุญธกานนท์ ) ( ตึกกว้างใหญ่ ประตูเล็ก ไม่สมดุล ... ตัวใหญ่ ปากเล็ก ได้ลาภน้อย ) . พรม การเลือกใช้สี จะเกี่ยวกับทิศ พรมสีดำไม่ได้มีปัญหาใด ในรูป พรมถูกตลบกลับมาด้านหนึ่ง ดูไม่เรียบร้อย . ป้าย Exit - ไม่ได้มีปัญหาใด ๆ ครับ เป็นข้อกำหนดโรงงานบางแห่ง จะต้องมีติดแจ้ง .
