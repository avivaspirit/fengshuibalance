ดูฮวงจุ้ยธุรกิจ: เยี่ยมชมบ้านลูกศิษย์ โครงการ The Plant Exclusique

📅 วันที่: 2016-11-09 📂 หมวดหมู่: ฮวงจุ้ยร้านค้า 📈 ความนิยม (WEI): 2,368
เยี่ยมชมบ้านลูกศิษย์ โครงการ The Plant Exclusique เป็น Case แรกสุด ... https://goo.gl/OPMA43 ( Case ที่ 2 กำลังตกแต่ง / Case 3 เพิ่งเขียนถึง ) ... เป็นบ้านเดี่ยวหลังใหญ่ เจ้าบ้านเป็นเจ้าของ SIT Interior จึงแตกแต่งบ้านเอง ระหว่างตกแต่งใกล้เสร็จ มีคนขอมาทั้งขอถ่ายรูป ( แอบถ่ายก็เยอะ ) ไปเป็นตัวอย่างสำหรับบ้านตนเอง เลยบอกเจ้าบ้านให้ขึ้นป้ายรับตกแต่งเป็นเรื่องราวซะเลย ... รูปแรกสุด เป็นบ้านแบบเดิม ๆ ของโครงการ รูป 2 - 3 เป็นบรรยากาศร่มรื่น จากการต่อเติมหลังคา และปูพื้นระเบียงยาวออกไป สำหรับงาน Party เล็ก ๆ ... เมื่อมองจากในบ้าน ปลายสุดมีบ่อน้ำพุทางยาวขนาดเล็ก มีเสียงจ๋อมแจ๋มเบา ๆ ตำแหน่งตามที่กำหนดไว้ ( ขนาดเล็กไปหน่อย น่ากว้างจะเท่าประตูบ้าน ) ... หากอ่าน Post เดิม ที่นี่ทิศทางองศารุ่งเรืองดีมาก ด้านหน้าเป็นโชคลาภ ( จึงเป็นประตู และตรงกับน้ำพุ ) ด้านหลังเป็นบารมี จึงให้ตั้งรูปสิ่งศักดิ์สิทธิ์ให้ตรงประตู เจ้าบ้านเลือก พ่อหลวงรัชกาลที่ 9 แต่ขนาดเล็กไปหน่อย เมื่อเทียบกับตัวบ้าน ( ดูฤกษ์ให้เปลี่ยนใหญ่ขึ้นอีกนิด ) ... แบบภายในเดิม ๆ ติดปัญหาเรื่อง "เสากลางบ้าน" ซึ่งเราได้กำหนดให้ทำฉากกั้นหุ้มเสา ให้เสาหายไป เจ้าบ้านดัดแปลงด้านหลังฉาก กั้นเป็นคอกสำหรับลูกเล่น ล้อมรอบไปด้วยเบาะนวม สำหรับน้อง Anna ที่ผมดูฤกษ์คลอดให้ https://goo.gl/bvY63X ... จุดนี้ เป็น Idea ที่ชอบมาก เพราะสะดวกสำหรับพ่อแม่ ผู้ใหญ่ในการดูแลน้อง และเป็นสัดส่วน เรียบร้อย สวยงาม ... ด้านข้างเป็นบรรยากาศห้องทานอาหาร และเชื่อมต่อไปห้องครัว ประตูห้องครัวเก๋มาก ตำแหน่ง Air / Coil ร้อนวางตำแหน่งโชคลาภ ครบถ้วน ถูกต้องหมด ... เนื่องจากข้างบนยังตกแต่งไม่แล้วเสร็จ เลยถ่ายมาให้ชมได้บางส่วน ตั้งแต่ห้องนอนน้อง Anna ในอนาคต มุมห้องทำงานแบบง่าย ๆ ของพ่อแม่ โทนบรรยากาศอบอุ่น สบาย ๆ ... FanPage ที่ชอบ Style การตกแต่งแบบนี้ เดี๋ยวจะหานามบัตรเจ้าบ้านมาแปะไว้ครับ ... เจ้าบ้านและภรรยาบอกว่า เข้ามาอยู่แล้ว มีความสุขสบายดี ใครมาเยี่ยมก็ชอบ ( ฝีมือเจ้าบ้าน ) แทบไม่ค่อยมีคนสังเกตุว่า มีการจัดฮวงจุ้ย ( รวมถึง เสากลางบ้าน ก็ไม่ใครกล่าวถึง ) เพราะการจัดฮวงจุ้ยให้ดีสุด ต้องสวย ถูกต้อง ใช้สอยในชีวิตประจำวันสะดวก แนบเนียน กลมกลืนไปกับตัวบ้าน . ชอบแนวคิด วิธีการจัดฮวงจุ้ย ที่ไม่มีการทุบทำลายใด ๆ ไม่มีการแขวนสิ่งแปลกปลอมแก้ไขไปทั่วบ้าน ( กระดิ่ง กระจก สิงห์ แปดเหลี่ยม บอลกระจก ... ) การปรับแก้ฮวงจุ้ยของเรา จะเน้นความสวยงาม การใช้งานได้จริงเสมอ ................................. Fengshui Balance ให้คำปรึกษาด้านฮวงจุ้ย ( ชัยภูมิ ทิศทาง ดวงจีน ฤกษ์ ) อย่างครบถ้วนถูกต้อง และเป็นระบบ สอดคล้องกับแบบสถาปัตย์ และการใช้งานจริง ( ลองศึกษา Post ผลงานที่ผ่านมาดูก่อนครับ ) ปรึกษาได้จนจบงาน ( Turnkey Project ) ติดต่อ : Line http://line.me/ti/p/twX0_SxVSX . #ThePlantExclusique #ฮวงจุ้ย
