จาก Post เรื่อง "ชง" ถามกันมาเยอะมาก ... วดป เวลาเกิด ตนเองเป็น นักษัตรใด จะแนะวิธีให้อย่างละเอียด

  • http://www.fourpillars.net/online4p.php
  • ใส่ วดป เวลาเกิด สากล ( ไม่ต้องแปลงข้ามประเทศ )
  • กด Calculate

สมมุติ ผลลัพธ์ได้ดังภาพ สังเกตุ แถบเหลือง เริ่มจากขวาสุด Year - Monkey ( ปีวอก ) Month - Goat ( เดือนแพะ ) Day - Rat ( วันชวด ) Hour - Horse ( ยามมะเมีย )

ไม่มี ขาล ( เสือ ) ในดวง คือ ไม่ชง กับปีจรวอก ( 4 กพ. 2559 - 4 กพ. 2560 ) . หากมีขาล คือ ชง แก้ตามที่แนะนำใน Post นั้น ข้อ 123 ( ย้อนกลับไปดู ) .

เนื่องจาก Post "ชง" ที่ผ่านมา พบว่า หลายท่านอ่านแบบรายละเอียดหายหมด ถามในสิ่งที่แจ้งไว้แล้วเกือบทั้งหมด ... ปีขาลชงไหม ? แก้ไขอย่างไร ? ... หนังสือซื้อที่ไหน ?

. เพื่อฝึกให้ท่านเป็นคนใจเย็น รอบคอบ ละเอียดถี่ถ้วน จับประเด็นได้ครบ ขอไม่ตอบคำถามใด ๆ เพิ่มเติมสำหรับ Post นี้ เพราะเชื่อว่า อธิบายครบถ้วนหมดแล้ว . TIP : อยากรู้ชะตาท่านเป็นอย่างไร ในปีนี้ ตย.ดูที่ช่อง DAY ตัวบน จะได้ Water ( ธาตุน้ำ ) แล้วเปิดหน้า 94 -96 ในหนังสือ ปฎิทินฤกษ์มงคล 2559 ของท่าน อ.เกรียงไกร บุญธกานนท์ มีจำหน่ายที่ Se-Ed หรือ B2S . Bonus : ใคร วดป ยาม มี ขาลครบทุกหลัก แจ้งมาได้ทาง inbox ... วิเคราะห์ดวงฟรี
