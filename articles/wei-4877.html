ผลงานอีกแห่งที่ Mandalay เป็นสถานเสริมความงาม ผลการดำเนินงานที่ผ่านมาอยู่ในเกณฑ์ดี น่าพึงพอใจ องศาอาคารดีมาก ด้านหลังมีบารมี ด้านหน้ามีโชคลาภ ( ศัพท์วิชาดาว 9 ยุคเรียก ทิศทาง "รุ่งเรือง" ) เมื่อด้านหน้ามีลาภ จึงให้เปิดประตูตรง Counter รับรอง

หลายคนกลัว ชง-ปะทะ กรณีนั่งชน หรือนั่งตรงแนวประตู แต่ที่ถูกต้อง หากเป็นองศาที่ดี ด้านหน้ามีลาภ นั่งตรงแนวประตู กลับจะได้ลาภมาก *** และหากด้านหลังเป็นดาวบารมี จัดวาง Logo ให้สวยเด่น ชื่อเสียงจะยิ่งโดดเด่น

ชง-ปะทะ ที่ต้องกลัวคือ เป็นถนนยาวพุ่งเข้าชน กรณีหลัง ต้องแก้ด้วยหลายวิธีการผสมผสานกัน่ ( รูปทรง สีปรับแก้ น้ำพุ วงเวียน ศาล ฯลฯ ) ให้เข้ากับทิศทางที่พุ่งเข้ามา รวมถึง ลักษณะชัยภูมิ รวมถึง สถาปัตย์ตกแต่ง Theme ของบริษัทฯ แบบหลัง บางกรณีก็แก้ยาก บางกรณีแก้แล้ว กลายเป็นดีมาก ( เปลี่ยนศัตรูเป็นมิตร )

ภาพบนเป็นด้านข้างอาคาร อีกภาพเป็นด้านหน้าอาคาร

Fengshui Balance ให้คำปรึกษาด้านฮวงจุ้ยอย่างครบถ้วนถูกต้อง และเป็นระบบ สอดคล้องกับแบบสถาปัตย์ และการใช้งานจริง ( ลองศึกษา Post ผลงานที่ผ่านมาดูก่อนครับ ) ปรึกษาได้จนจบงาน ( Turnkey Project ) ติดต่อ : Line http://line.me/ti/p/twX0_SxVSX
