เมรุซ้าย เป็นเมรุไฟฟ้า ไม่ส่งผลกระทบต่อสิ่งแวดล้อม ไม่มีผลกระทบด้านลบต่อฮวงจุ้ย ลักษณะแท่งปลายแหลม มีความหมาย พู่กัน หมายถึง ปัญญา

เมรุขวา มีปล่องปล่อยควัน ผลกระทบมีมาก ( กลิ่น ควัน ฝุ่นละออง มลพิษ .... กระทบ ตา จมูก ปอด ) ความหมาย เผาไหม้ ทำลาย ( ธาตุไฟรุนแรง ) ผลกระทบ : เจ็บป่วย หน้าที่การงานมีปัญหา เสียลาภ "ไร้บุตร" รุนแรงสุด ชั้นที่อยู่ตรงกับความสูงปล่องเมรุ รองลงมา มองเห็น อยู่ใกล้ ผลกระทบน้อย มองเห็น อยู่ไกล

การแก้ไข

  • อยู่ใกล้ ปิดหน้าต่าง + มู่ลี่ หรือม่านสีธาตุดิน
  • พลังของธาตุ ไฟ ให้กำเนิด ดิน ( สีเหลือง ครีม ไข่ไก่ )
  • อยู่ไกล ปลูกต้นไม้บัง / ทำเชิงชายสีธาตุดิน บังตา

Note : โดยปกติ เวลาเลือกที่ดิน จะหลีกเลี่ยงปล่องเมรุ เป็นอันดับแรก เพราะแก้ไขยาก และผลกระทบมีมาก
