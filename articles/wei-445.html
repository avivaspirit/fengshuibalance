ฮวงจุ้ยบ้านและที่อยู่อาศัย (Residential Fengshui)

ดูฮวงจุ้ยบ้าน: ประตูบานไหน คือประตูบ้านหลัก ? — ประตูบานไหน คือประตูบ้านหลัก —…

📅 วันที่: 2016-10-08 📂 หมวดหมู่: 🏠 บ้าน 📈 ความนิยม: 1,768
ประตูบานไหน คือประตูบ้านหลัก ? เพราะขนาดประตูทั้งสองใหญ่ใกล้เคียงกัน และอยู่ใกล้กัน สร้างความสับสนแก่แขกผู้มาเยือน ว่าควรเดินเข้าบานไหน ... จากภาพ ประตูใหญ่เข้าบ้าน อยู่ด้านขวา ประตูโรงรถใหญ่ใกล้เคียงกันอยู่ซ้าย ( เจ้าบ้านเชื่อตามผู้รับเหมา ) ... ยังดีที่ประตูใหญ่ มีช่องกระจกด้านข้าง ทำให้เกิดความแตกต่างจากอีกบาน https://goo.gl/FkcCLV ... ไม่เช่นนั้น คงสับสนกว่านี้ เพราะทั้งขนาด สี ตำแหน่ง ใกล้เคียงกัน ... ผลในด้านฮวงจุ้ย ภาพลักษณ์ไม่เด่นชัด สับสน วุ่นวาย ... แนะนำการแก้ไข 1. ทาสีประตูโรงรถ ให้เป็นสีเดียวกับผนังบ้าน ... เพื่อกลมกลืน ไม่ให้เกิดความโดดเด่น 2. ทาขอบคิ้ว Frame ประตูบ้าน เป็นอีกสี ... ไม่จำเป็นต้องทาหนาเท่า อาจทาเพียง 1/2 ... เพื่อให้เกิดความเด่นจากสิ่งแวดล้อมข้าง ๆ ... สำหรับองศาหลังนี้ แนะนำสีฟ้า หรือเทาอ่อน 3. วางพรมสีน้ำเงินหน้าประตูบ้าน ... ส่วนเสา ไม่ได้ขวางประตู และตรงกับแนวสันกำแพง ถือว่าปกติ ไม่ได้มีผลลบใด ๆ ... หลังนี้ ยังมีต่อภาค 3 ... แต่คราวนี้เป็นด้านใน ... เนื้อหาดี มีประโยชน์ โปรดช่วย Share ... อ่านสาระฮวงจุ้ยอย่างมีแนวคิด ✔ กด Like เพจ ✔ กดติดตาม เลือก "See First / เห็นก่อน" ( นโยบายใหม่ Facebook ท่านจะเห็นเราน้อยลงมาก ) ( ยกเว้น กดเลือก See First )

จัดปรับพื้นที่และสถาปัตยกรรมตามหลักฮวงจุ้ย
